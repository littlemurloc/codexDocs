# 城镇底图 · 三层切分需求

> **给接手的出图方**：这份文档只讲一件事 —— 把**已经交付的那张街景底图**拆成三张图层。
> 配套图：`town_layers_annotated.png`（分区标注）、`HUD_TOWN_LAYERS.png`（反例）。
> 建筑单体、界面控件都不在本文范围内，那些是另一份需求。

---

## 0. 要做什么

把现有的 `bg_town_scene.png`（750×1334 的城镇街景）**拆成三张同尺寸图层**：

| 层 | 内容 |
|---|---|
| `bg_far.png` | 天空 / 云 / 城堡废墟 / 远山 / 雾 |
| `bg_mid.png` | 路面 / 石板 / 草地 / 贴地的碎石 |
| `bg_near.png` | **立在地面上、能挡住后面的物件**（透明底） |

三张按 `far → mid → near` 叠回去，必须和原图一模一样。

---

## 1. 为什么是三层，不是两层

我们试过「按地平线切成远景 / 前景两层」—— **不行**，见 `HUD_TOWN_LAYERS.png`。
那条线会把「地面」和「植被」划进同一层，于是任何插在中间的东西都会被整片地面盖住，
只剩最上面一截露出来。

所以必须把「地面」和「立在地面上的物件」分开，`bg_near` 才是可以压在别的东西上面的那一层。
**这也是 `bg_near` 必须是透明背景的唯一原因。**

---

## 2. 切分的唯一判据

对画面里每一样东西问一句：**它是「躺在地上」还是「立起来挡住后面」？**

| 情况 | 归到 | 例子 |
|---|---|---|
| 躺在地上、贴着地面的 | `bg_mid` | 路面、石板缝、草丛、碎石、土地纹理、栅栏的**影子** |
| 立起来、比半人高、能挡住后面的 | `bg_near` | 枯树、吊灯、木箱堆、木桶堆、栅栏本体、灌木丛 |
| 在街道尽头、属于远景的 | `bg_far` | 天空、云、城堡与废墟剪影、远山、雾 |

判不准时按这条走：**上边缘明显高出地面轮廓线 → 进 near；贴着地面轮廓线 → 留在 mid。**

---

## 3. 必须切进 `bg_near` 的物件清单

对着标注图 `town_layers_annotated.png`（红点编号）逐项做：

| # | 物件 | 位置（在 780×1400 参考图里） | 注意 |
|---|---|---|---|
| 1 | 右侧枯树 | 右边缘，x 600–780，y 300–780 | **整棵**，含所有细枝；树冠不能漏 |
| 2 | 左侧枯树 | 左边缘，x 10–110，y 380–560 | 同上 |
| 3 | 街心吊灯 | x 320–390，y 560–700 | 含灯杆、横臂、灯罩、灯里的暖光 |
| 4 | 左中木箱堆 | x 110–260，y 650–770 | 木箱 + 旁边散落的木板 |
| 5 | 右下木桶堆 | x 560–700，y 650–790 | 木桶 + 石块堆 |
| 6 | 地平线灌木丛 | 沿地平线共约 5 丛，x 60–600，y 520–660 | 每丛单独算，别连成一片 |
| 7 | 栅栏 | 左段 x 60–300 / 右段 x 420–610，y 600–720 | 栏杆与立柱；栅栏**投在地上的影子**留在 mid |

> 树和灌木：**枝叶之间的空隙必须是真透明**，能透出后面。不要用「连成一整块」的做法。

---

## 4. 技术规格（硬性）

| 项 | 要求 |
|---|---|
| 尺寸 | 与现有底图**完全一致**：750×1334（或 2x：1500×2668，三张同一倍率） |
| 位置 | 三张必须**像素级对齐**：叠回去要和原图一模一样，不能裁切、缩放、位移 |
| 格式 | `bg_far.png` / `bg_mid.png` 不透明即可；`bg_near.png` **必须 RGBA 透明底** |
| 边缘 | 物件外缘羽化 **1–2px**，不要硬边（硬边压在浅色背景上会有一圈黑边） |
| 命名 | 严格用 `bg_far.png` / `bg_mid.png` / `bg_near.png` |

**验收方法**（出图前自己过一遍）：
三张按 `far → mid → near` 叠起来，和原图逐像素对比，
**除了物件边缘 1–2px 的羽化，不应该有任何差异**。有差异就是切歪了。
