## 一、五个必须懂的词

玩家只要记住这五个，剩下的都能猜。

| 词 | 英 | 一句话 | 备注 |
|---|---|---|---|
| **空腔** | the Hollow | 井底下那个会饿的洞 | 民间叫法。官方文书叫"第七竖井" |
| **井肉** | stock | 洞里长出来的东西 | 会动、会咬人、能吃。**不叫怪物** |
| **饿** | the Hunger | 洞底下那个东西 | 不是神，不是恶魔。没有身体，杀不死 |
| **脂** | tallow | 点灯和起锅共用的那一罐油 | 全队只有一罐。亮着就没得吃，吃了就得摸黑 |
| **烙** | the mark | 吃井肉吃多了，身上长出来的东西 | 长鳞、长毛、耐渴、夜视。是构筑，不是惩罚 |

## 三、停用词与替代（改稿时按这张表替换）

| 停用 | 换成 | 原因 |
|---|---|---|
| 灶谱 | **食谱** | "灶谱"要解释；"食谱"不用 |
| 井货 / stock | **井肉**（口语）/ 货（公文） | "货"是会计词，第一眼不吓人也不馋人 |
| 炼化 / rendering | **在长** / 长歪了 | "炼化"像工业术语；"它在长"本身就可怖 |
| 火候四级（生食/汆洗/炙/配伍） | **生 / 熟 / 精** | 三档够用，玩家不用记表 |
| 未被餍足者 / the Unfed | **饿**（口语）/ 那个饿的东西 | 保留不可名状感，但得让人叫得出口 |
| 见证 / 法庭 | **它还认你** | 机制不变，砍掉法律隐喻 |
| 未结清的账 | **欠账** | 少三个字，意思一样 |
| 带印 | **烙上印** | 动词化，玩家一看就知道是被动结果 |
| 抵押 / 没收 / 清算 | 保留，但只作**背景传说**与 NPC 台词 | 不做章节标题，不做理解前提 |
| 契约 / 主体 / 等价物 | 只出现在学者与教会争吵的场景 | 同上 |

## 四、写作用词的四条规矩

1. **第一次出现，当句解释。** 例：「全城只有一口井，所有人的钱都来自把东西吊上来——城里人管这些还没长完的东西叫**井肉**。」
2. **一个词只干一件事。** 不要用"账"同时指压力、金币和契约；金币是"状票"，压力是"欠账"。
3. **公文腔只给公文。** 下井状、账房、衙门的文本可以冷、可以绕；旁白和战斗文案一律说人话。
4. **黑色幽默一节最多一句。** 多了就变成作者在抖机灵，玩家会开始怀疑自己在读散文而不是设定。

- "绞盘渡"是否保留。它画面感强，但第一次听像渡口，可能需要在 UI 里配一行小字：**绞盘渡 · 井口上的城**。
- 英文名是否全部重起（现在的 the Hollow / the Unfed 是给欧美读者看的，如果目标市场是国内，英文只作内部代号）。
