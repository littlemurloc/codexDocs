# 底部导航图标 · 出图需求

> 交付：**3 张 512×512 透明 PNG**。
> 用途：替换游戏主界面最下方那三个导航按钮的图标。
> 附件：`dock_icons_spec.png`（规格示意）、`dock_icons_ref.png`（现有画风参考）、
> `dock_in_context.png`（实机位置）。

---

## 0. 先说最重要的一条

这三颗图标在屏幕上**只有 44 和 62 像素**。

现有素材是 40px 的，被放大到 44/62 显示，所以糊了——金币已经看不出是金币。
**新图请按 512×512 交付**，等于给足余量让程序缩小。

判断标准只有一个：**缩到 44 像素还认得出是什么，才算过。**

---

## 1. 用在哪

游戏主界面最下方是一条 160px 高的深色横栏，三颗按钮横向排开：

| 位置 | 名称 | 圆托直径 | 图标显示尺寸 |
|---|---|---|---|
| 左 | 城镇（当前所在页） | 60 px | 44 px |
| 中 | 出征（主按钮） | 82 px | 62 px |
| 右 | 商店 | 60 px | 44 px |

中间那颗**故意更大、位置更高**——它是这一屏唯一「该点的地方」。

**圆托、金色圆环、光晕、文字都由程序绘制，请只画图标本身。**

---

## 2. 三颗各画什么

### 2.1 城镇 `icon_town`

- **要表达**：这是我住的那座镇子。
- **建议母题**：2~3 栋**尖顶小屋的剪影**（带烟囱、一两扇透出暖光的窗），
  或者一扇带拱的**镇门**。
- **要避免**：不要画人像 / 半身像 / 单个屋顶。
  现在用的就是半身像，玩家容易读成「角色」、「名册」，而不是「城镇」。
- **一眼要读成**：一片建筑群，不是单个盒子。

### 2.2 出征 `icon_gate`

- **要表达**：出发，去下一个副本。
- **建议母题**：**卷起的羊皮地图 + 一把匕首压在上面**；
  或「插在地上的路标 + 远处城门剪影」。
- **要避免**：不要只画一个卷轴/信卷——那个已经是任务板的图标（`icon_deed`），
  两者会撞。
- **一眼要读成**：要去某个地方，有方向感。

### 2.3 商店 `icon_shop`

- **要表达**：买卖装备与补给。
- **建议母题**：**鼓起的钱袋 + 两枚散落的金币**；或「天平 + 金币」。
- **要避免**：不要只画一枚金币。金币图标在顶栏、结算、商店价格里已经用了很多次，
  再画一枚就没有辨识度。
- **一眼要读成**：钱袋的**扎口绳**是这个母题的识别点，请保留。

## 3. 技术规格

| 项 | 要求 |
|---|---|
| 画布尺寸 | **512 × 512**，正方形 |
| 格式 | PNG-24 带 alpha（**透明背景**，不要白底、不要黑底） |
| 内容占比 | 画布 **78%~84%**，四周各留 **8%~11% 透明边** |
| 主体线宽 | 在 512 画布上 **14~18 px** |
| 命名 | `icon_town.png` / `icon_gate.png` / `icon_shop.png` |
| 交付方式 | 三个**独立文件**，不要拼成一张图、不要带棋盘格背景 |

**关于线宽**：512 缩到 44 是 8.6%，512 上的 16px 线缩完只有 1.4px。
所以细则线会直接消失——**不要画细于 8px 的线**（按 512 画布算）。

**关于边距**：图标要放进圆形托里，四周必须留空。
内容顶到画布边缘的话，进圆之后会被圆环切掉。

---

## 4. 风格

这套 UI 是**墨线版画**的感觉，不是矢量图标、不是 3D 渲染：

- **外轮廓**是一条略有起伏的深色描线（不要光滑得像 AI 矢量描边），
  转折处可以有轻微的粗细变化；
- **内部**用短线排线（hatching）做出体积，不要用平滑渐变；
- 整体偏**暖铜金**，像旧黄铜、旧金箔。

### 色板

| 用途 | 色值 |
|---|---|
| 高光 | `#e8c47a` ~ `#d3a24e` |
| 主体 | `#a9793c` |
| 暗部 | `#4a3826` |
| 描线 | `#241c14` |
| 点缀（可选，少量锈红） | `#6b3f2f` |

**请不要用**：纯白高光、纯黑描边、蓝紫等冷色、发光、外发光。

参考图：`dock_icons_ref.png` 里是现有图集，新图画成同一套即可。

---

## 5. 明确不要的东西

1. **不要画圆盘 / 圆环 / 底座**——程序会画；
2. **不要画投影、外发光、光晕**——程序会画；
3. 不要文字、字母、数字；
4. 不要四角装饰、边框、花纹外框；
5. 不要细于 8px 的线（按 512 画布）；
6. 不要写实照片感、不要 3D 渲染感、不要赛博/科幻风格。

---

## 6. 交稿前请自检这四条

1. 把图缩到 **44×44**，还认得出是什么吗？（这条是硬指标）
2. 放到深色底 `#0a0a0c` 上，边缘有没有白边 / 黑边 / 半透明脏边？
3. 放进 60px 的圆里（四周各留 8px），有没有顶到边？
4. 三张并排看，**线条粗细、明度、笔触**是不是同一套？
   （三张里有一张偏亮或偏细，放在一起就会像两个人画的）
