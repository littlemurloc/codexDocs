## 二、已收到文件里要改三处

### 2.1 画布尺寸：2048 → 1024

交付的 `ATLAS_A` / `ATLAS_B` 都是 **2048 × 2048**。

我们按 1024 的坐标切图（`x = (n % 4) × 256`），2048 的图会让切出来的位置全部偏移一格。
**A、B、C 三张请统一 1024 × 1024。**

> 如果工具只能导 2048，也可以，但请在 README 里写明实际尺寸 —— 不要默认我们知道。

### 2.2 `ATLAS_A` 的背景：棋盘格不是透明

`ATLAS_A` 交的是 **JPG**，背景是**画上去的棋盘格**（灰白方格直接画在像素里，
整张图 alpha 全是不透明的）。

JPG 格式本身就不可能带透明通道，所以看到「棋盘格」时要意识到：
**那是画出来的图案，不是透明**。

请改成：

| 方案 | 做法 |
|---|---|
| **首选** | 直接导出 **PNG，alpha = 0**（真透明） |
| 备选 | 纯品红 `#FF00FF` 底（像你交的 `ATLAS_B` 那样，那个是对的） |

**不要画棋盘格、不要画灰白方格、不要用「看起来像透明」的贴图。**
我们抠图时，棋盘格和「大理石半身像」的浅灰很难分开，会误伤图标。

### 2.3 `bg_town` 是三段重复的

交付的 `bg_town` 是 **1536 × 2752**，里面**上下重复了三次同一个场景**，
中间还有黑边隔开。这没法当整屏背景用。

需要的是：**750 × 1334 单张完整竖构图**，一个场景画到底，
不要分镜、不要三联、不要拼贴。

> 如果重出，要求同 `bg_battle`：昏暗村庄广场、远处建筑剪影、中间留暗部给面板、
> 平均亮度 ≤ 30%。**不要画人物。**
