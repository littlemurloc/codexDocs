# 游戏内图标 · 第二批出图需求

> 交付：**30 张 256×256 透明 PNG**，分四组。
> 附件：`ui_icons_spec.png`（规格与显示尺寸对照）、`icon_style_ref.png`（现有画风参考）、
> `ui_context_*.png`（四处实际使用场景）。

---

## 0. 先说三件事

**一、这批不是「一个东西一张图」。**
游戏里技能 105 个、饰品 490 个。逐个画不可能，所以按**类型**出：
技能 6 类、饰品形态 10 类。程序按规则把每个技能/饰品映射到某一类。

**二、图标在屏幕上很小。**
技能卡上的图标只有 **30~36 像素**，饰品格子最大 **96 像素**。
判断标准只有一条：**缩到 30 像素还认得出是什么，才算过。**

**三、交付尺寸统一 256×256，不是按显示尺寸画。**
256 是给足缩小余量。千万别按「30px 那么大」去画细节——那会糊成一团。

---

## 1. 通用规格（四组都一样）

| 项 | 要求 |
|---|---|
| 画布 | **256 × 256** 正方形 |
| 格式 | PNG-24 带 alpha，**透明背景** |
| 内容占比 | 画布 **78%~84%**，四周各留 **8%~11% 透明边** |
| 主体线宽 | 256 画布上 **8~12 px** |
| 命名 | 见下文各组的文件清单，全小写、下划线 |
| 交付方式 | 一张一个文件，不要拼图、不要带棋盘格背景 |

**关于线宽**：256 缩到 30 像素是 11.7%，10px 的线缩完只有 1.2px。
所以**不要画细于 6px 的线**（按 256 画布算），细则直接消失。

**关于边距**：图标要放进圆角格子或圆环里，四周必须留空。
内容顶到画布边缘，进格子之后会被裁掉。

---

## 2. 风格

这套 UI 是**墨线版画**的感觉，不是矢量图标、不是 3D 渲染：

- **外轮廓**一条略有起伏的深色描线（不要光滑得像 AI 矢量描边），转折处可有轻微粗细变化；
- **内部**用短线排线（hatching）做体积，不要用平滑渐变；
- 整体偏**暖铜金**，像旧黄铜、旧金箔。

### 色板

| 用途 | 色值 |
|---|---|
| 高光 | `#e8c47a` ~ `#d3a24e` |
| 主体 | `#a9793c` |
| 暗部 | `#4a3826` |
| 描线 | `#241c14` |
| 点缀（少量锈红，用于「伤害/负面」类） | `#6b3f2f` |
| 点缀（少量冷绿，用于「治疗」类） | `#5c7a52` |

**不要用**：纯白高光、纯黑描边、荧光色、外发光、渐变发光。

参考图：`icon_style_ref.png` 是现有图集，新图画成同一套即可。

## 3. A 组 · 技能图标（6 张）

游戏里 105 个技能，程序按「效果」归到这 6 类。每张要能代表一整类。

### 3.1 `sk_melee.png` — 近战打击

- **代表**：贴身砍、砸、刺（十字军的剑、强盗的匕首、食尸鬼的爪）
- **母题**：一把**斜劈的短兵器**（剑刃或战锤），刃口带一小段挥砍弧线
- **要避免**：不要画整只手握剑——30px 下手指全糊，只剩一团

### 3.2 `sk_ranged.png` — 远程射击

- **代表**：弩、火枪、投掷、毒气（瘟疫医生的炸弹也算这一类）
- **母题**：一支**箭头 + 一点飞行尾迹**，或一把**上弦的弩**
- **要避免**：不要画完整的弓（弦和弓臂在 30px 下会糊成弧线）

### 3.3 `sk_heal.png` — 治疗

- **代表**：回血、解除流血/中毒、战地包扎
- **母题**：**绷带卷 + 一滴血**，或**药瓶 + 十字**
- **要避免**：不要用现代医疗十字（红十字）——和这套中世纪风格不合

### 3.4 `sk_buff.png` — 增益

- **代表**：加攻击、加防御、加速、给队友上状态
- **母题**：**向上指的箭头 + 一圈光环**，或**举起的酒杯/号角**
- **要避免**：不要画成「加号」——加号在 UI 里表示「添加」，会误读

### 3.5 `sk_debuff.png` — 减益 / 削弱

- **代表**：降攻、降防、减速、上虚弱
- **母题**：**向下指的箭头 + 裂纹**，或**一只掐住的手**
- **要避免**：不要和增益只靠「箭头方向」区分——两个图标并排时方向不明显，
  请让形状本身不同（比如减益用「裂开的盾」）

### 3.6 `sk_move.png` — 位移

- **代表**：击退、拉近、换位、冲锋
- **母题**：**两个相反方向的箭头 + 一个脚印**，或**交叉的双箭头**
- **要避免**：不要画成「四条箭头」的移动图标（像手机的方向键）

## 5. C 组 · 饰品形态（10 张）

游戏里有 **490 件饰品**，逐个画不现实。做法是：按**物件形态**分 10 类，
程序按饰品 id 自动归类，玩家看到的是「这是个药瓶 / 这是根羽毛」+ 稀有度色框。

| 文件 | 形态 | 覆盖的典型饰品 |
|---|---|---|
| `tr_vial.png` | 药瓶 / 药剂 | 各种油、酊、药水 |
| `tr_feather.png` | 羽毛 | 鸦羽、鹰羽这类 |
| `tr_ring.png` | 戒指 / 指环 | 各种戒指 |
| `tr_pendant.png` | 吊坠 / 护符 | 挂在脖子上的小物件 |
| `tr_page.png` | 书页 / 卷轴 / 笔 | 手稿、笔记、地图碎片 |
| `tr_weapon.png` | 兵器小件 | 匕首、弹丸、箭头、枪械零件 |
| `tr_cloth.png` | 衣物 / 布片 | 外套、手帕、面具、胡子蜡 |
| `tr_bone.png` | 骨头 / 牙 / 爪 | 骨制品、獠牙、爪子 |
| `tr_vessel.png` | 容器 / 盒子 | 小箱、罐子、灯笼、提灯 |
| `tr_relic.png` | 遗物 / 圣物 | 祖先遗物、战利品这类「不像日用品」的东西 |

**统一要求**：
- 这 10 张**不要画成「完整插画」**，要画成**剪影 + 少量内部线条**——
  因为它们会被放在彩色格子里，细节多了会和底色打架；
- 每张的**外轮廓必须彼此不同**：玩家靠形状区分，不靠文字；
- 不要画文字、不要画价格标签、不要画挂绳以外的装饰。

## 8. 交稿前请自检

1. 把图缩到 **30×30**，还认得出是什么吗？（硬指标）
2. 缩到 96×96（饰品那组），细节有没有糊成一团？
