## 4. 「可互动」怎么表现（**这一节是重点**）

要求是：**建筑本身要和底图融合**（同一笔触、同一光照），
但玩家一眼能看出「这个能点」。所以做成**两层**：

### 4.1 交付方式（两种择一，强烈建议 A）

**A · 分层（推荐）**
1. `bg_town_scene.png` —— 完整底图，8 个位置上画**地面、阴影、光斑、被压住的道具**，
   但建筑本体留空（空槽处理好，不能露白）；
2. `bld_<id>.png` × 8 —— 每栋建筑单独一张、透明背景、只含建筑本身（含它的落地影）。

这样程序能对单独的建筑做「悬停变亮 / 按下微沉」，底图不会跟着亮。

**B · 合成（省事但受限）**
一张 750×1334 成品图。代价：8 个点无法单独高亮，只能靠程序画一个框 —— 会有「贴纸感」。

### 4.2 三个状态（A 方案由程序做，你只需保证素材支持）

| 状态 | 表现 | 素材要求 |
|---|---|---|
| 常态 | 亮度 ~85%，边缘融进环境 | 建筑件边缘不要留硬描边 |
| 悬停/按下 | 提亮到 100% + 底部一圈暖光晕 + 轻微上浮 4px | 建筑件**四边留 8px 透明边距**，避免上浮时切边 |
| 红点 | 建筑上方挂一块木牌（程序画），木牌右上角红点 | 木牌不用你画 |

### 4.3 名牌（程序画，仅供你避让）

每栋建筑**底部居中**会压一块深色名牌写名字（宽度取建筑宽的 86%，约 84–118，高 26）。
请你保证**建筑最下面 26px 内不要放必须看见的关键细节**（炉火、招牌、车轮下半截都别放这一条里）。
牌子贴着地面，和建筑永远对得上 —— 挂在头顶的话，远排的牌子会飘在空中，看不出属于哪栋。

## 7. 底图必须分三层（第二轮需求）

### 7.1 为什么要分层

现在底图是一张合成好的图，建筑只能整张贴在上面 —— 结果：
路边的枯树、街心的吊灯、近处的木箱**全部被建筑盖住**，
而它们本来是「在建筑前面」的东西。玩家一眼就看出来建筑是浮在画面上的。

正确做法是把底图拆成三层，我们按 `远 → 中 → 建筑 → 近` 的顺序合成。

### 7.2 三层怎么切（**这是硬要求，请按这个交**）

我们试过「只切远景 / 前景两层」——**不行**：那条分界线把「地面」和「植被」划在同一层，
建筑夹在中间时整栋会被地面盖住，只剩屋顶（实测图 `docs/HUD_TOWN_LAYERS.png`）。
所以必须是三层，建筑插在 **中** 与 **近** 之间：

| 文件 | 内容 | 合成顺序 |
|---|---|---|
| `bg_far.png` | 天空、云、远处城堡废墟、远山、雾。**不含**街道与地面 | 第 1 层 |
| `bg_mid.png` | 路面、石板、草地、**围栏、远处的地面杂物**（凡是躺在地面上的） | 第 2 层 |
| ← 建筑画在这里 → | | |
| `bg_near.png` | **立在地面上、比人高的物件**（带透明）：右侧枯树、街心吊灯、近处木箱木桶堆、画面底部两角的杂草 | 第 3 层 |

切分的唯一判据：**这个东西是"躺在地上"还是"立起来挡住后面"**。
躺着的进 mid，立着的进 near。草丛贴着地面 → mid；高到能挡住建筑 → near。

三张都必须是**完整画布尺寸、同一位置**（不能裁切、不能缩放），叠起来要和原图完全一致。
`bg_far` / `bg_mid` 不透明即可，只有 `bg_near` 必须是透明 PNG。

> 为什么必须你们来做：我们试过按亮度自动抠 —— 这张图里灌木、栅栏、地面的暗部
> 亮度几乎是同一档（实测 10–60 完全重叠），阈值切开不是漏就是溢，抠不干净。

### 7.3 顺便修两条融合问题

1. **建筑底部不要直切**。现在八张单体图的下沿是一条硬边（抠图按内容框裁的），
   贴到场景里就是一条直线，像剪贴画。请在底部留 **10–15px 的地面/阴影过渡**
   （脏污、草、碎石都行），让建筑「陷」进地面。
2. **光照要跟场景一致**。场景是「冷灰月光 + 街心一盏暖灯」，
   而单体建筑各自画了一套明亮的光。请统一成：
   整体偏冷（青灰）、只在炉火/窗内保留暖黄，暗部不要黑到纯黑（`#1a1c20` 就够）。
