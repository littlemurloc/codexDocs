# 界面信息审计（M109）

对照原版《暗黑地牢》的信息呈现，逐系统核对「数据里有、界面上没有」的部分。
方法：先扫数据字段，再查每个字段/API 在 `src/view/` 里的引用次数——
**引用为 0 的就是没展示**，不靠肉眼翻截图判断。

## 结论速览

| 系统 | 主要缺口 | 数据齐不齐 | 改动成本 |
|---|---|---|---|
| 英雄详情 | 抗性 6 项、疾病/怪癖只有计数没有内容 | 齐 | 低 |
| 战斗 | 实际命中率、目标抗性 | 齐 | 中 |
| 饰品 | 全量效果、谁戴着 | 齐 | 低 |
| 技能 | 技能等级（只有图标分级，无数值） | 部分 | 高 |
| 城镇 | 建筑升级（完全不支持） | 无 | 高 |
| 商店 | 卖东西（已支持，但入口不明确） | 齐 | 低 |
| 结算 | 经验明细、怪癖/疾病获得提示 | 齐 | 低 |
| 地图 | 基本完整 | 齐 | — |

## 1. 英雄详情（`_draw_hero_sheet`）

**已有**：头像、职业、等级、装备阶、压力条、出征/阵亡次数、
技能列表（每条带一行描述和图标）、饰品两格、疾病/怪癖**计数**。

**缺**：

| 原版有 | 我们 | 说明 |
|---|---|---|
| 6 项抗性（眩晕/中毒/流血/死亡/疾病/位移） | **完全没有** | `campaign.resist_of()` 在 UI 里引用 **0 次** |
| 怪癖名 + 各自效果 | 只有「负 2」 | `_quirk_effect_text()` 已能生成文本，没地方显示 |
| 疾病名 + 各自效果 | 只有「病 1」 | 同上 |

原版把这三块分开列，因为它们是「这个人为什么打不好」的全部原因。
只给计数等于告诉玩家「你有病」却不说是哪种。

## 2. 战斗

**已有**：HP、压力、DOT、buff、状态标签、行动序、技能卡的伤害/暴击/命中修正、目标选择面板。

**缺**：

- **实际命中率**。技能卡写「命中 +85%」，但对面闪避多少、有没有 buff，
  玩家算不出来。原版战斗里点技能会显示 `Hit Chance: 85%`，是对这个目标的实际值。
- **目标抗性**。施加眩晕/流血时，对面有多少抗性决定成功率，界面上没有。

## 3. 饰品

**已补（M108）**：图标、稀有度色、效果摘要。

**缺**：

- 点选后看**全部效果**（有些 4~5 条，摘要只 2 条）——`_draw_trinket_detail()` 现成。
- **「已装备于 X」**。同一件不能给两个人，现在装失败只说「已被占用」，不说是谁。
- **flavor 描述**：数据里没有。原版那句话在本地化文件里，`data/trinkets.json`
  是纯数值提取，没带文案。490 件补不回来。

## 4. 技能

**已有**：7 选 4、每技能一行描述、图标、已装标记。

**缺**：**技能等级**。数据里每个技能有 5 级（`levels[0..4]`），
代码只用 `levels[0]`；`_skill_level_of()` 的结果只喂给图标分级，**数值从不显示**。
原版技能可以升级（公会花钱），升级后伤害/命中/暴击都会变。

这是缺口里最贵的一个：要接「技能经验/升级费用/等级影响」，等于一个小系统。

## 5. 城镇

**已有**：8 座建筑、名册条、资源条、周次。

**缺**：**建筑升级**。原版可以花钱升级建筑（公会 → 更多技能位、铁匠 → 更高装备阶）。
本项目 `upgrade_building` 引用 **0 次**，等于不支持。

## 6. 商店

**已有**：饰品货架（买）、补给柜台、价格、稀有度、卖东西（`sell` 有实现）。

**缺**：卖东西的入口不明确——玩家不知道手上不要的饰品能换钱。

## 7. 结算

**已有**：金币/纹章/饰品、宝石折价、经验、队伍状态。

**缺**：

- **经验明细**：谁升了级、现在多少级。
- **怪癖/疾病获得提示**：这趟谁染了什么，结算里不写就只能去英雄面板猜。

## 8. 地图

基本完整：房间类型、走廊事件、光照、侦察进度、背包余量（M105）、任务进度。

唯一可加的是「已侦察房间的**内容**预览」（现在是只知道类型，不知道里面有什么）。

## 建议的实施顺序

按「信息缺口大 + 成本低」排：

1. **英雄详情补抗性 + 怪癖/疾病明细**（半天，数据全在，只是画出来）
2. **饰品：全量效果 + 谁戴着**（半天，复用现成函数）
3. **战斗：实际命中率**（一天，要算目标闪避 + buff）
4. **结算：经验明细 + 染病提示**（半天）
5. 技能等级 / 建筑升级（各是一个小系统，要先定规则）

前四项都不涉及规则改动，只动展示层——改完不会影响任何 bench 数字。
