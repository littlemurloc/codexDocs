- **旧文档里的「数据没有 X」也要复核**：M26 写的「cleanse/gather 缺目标数量」
  是错的，数量一直在 `data.amount` / `data.percentage` 里，M32 读了才发现。
- **新增 `class_name` 文件后要先重建类缓存**，否则测试报
  `Nonexistent function 'new'` / `Identifier not declared`：
  `"$GODOT" --headless --path . --editor --quit`（会写 `.godot/global_script_class_cache.cfg`）。
  这不是语法错，别去改代码。
- 界面排版要按 **1080 宽**验一遍：M31 按 1280×760 排的，缩到 1080 时
  顶部状态条会和新加的文字叠在一起（M32 的任务行就是这么发现的）。
- **名册的 key 是实例 id**（M34）：`crusader` / `crusader#2`。
  一条规则贯穿：**查数据用 `def_of(key)`，记状态用 key 本身**。
  新增任何"问某个英雄要数值/技能/职业限制"的代码，都要先过 `def_of`；
  新增任何"记某个英雄的状态"的字典，键必须是 key。
- **`_text(..., HORIZONTAL_ALIGNMENT_RIGHT, w)` 的 x 是文本框左边界**，不是右边界。
  必须写 `x = 右边界 - w`，否则整段画到屏幕外、而且**不报错、看不出**。
  M46 查出三处（地图屏「侦察 %」偏出 176px，从加上那天起就没显示过）。
- **加了新界面状态后要重跑自动化**：主菜单（M47）之后 `--shot=` 单独用截到的是菜单，
  截城镇得带 `--save=user://x.json` 或 `--click=slot:0`。
- **批量改名之后要 grep 新名字**：M34 把 `DdNames.hero_name(` 全替换成
  `_hero_label(`，把它自己函数体里那行也换了，运行时无限递归。
  这类错编译能过、单测能过，只在特定存档上崩。
- **Godot 命令行参数必须写在 `--` 之后**（M57 踩了半天）：
  `OS.get_cmdline_user_args()` 只返回 `--` 之后的参数。写成
  `godot --path . --start --battle` 不会报错、窗口照开、但什么都不会发生
  （不截图、不进战斗）。正确：`godot --path . -- --start --battle`。
  旧文档里的命令都省了 `--`。
