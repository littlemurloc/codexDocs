## 4. 动手前对照表（M133~M145 这一串踩出来的）

> 每一条都是「写的时候觉得没问题、跑起来才发现」的。写完一段代码，
> 拿这张表过一遍，比事后 debug 便宜得多。

### 分发与状态机

1. **两个分发函数互相兜底 = 无界递归**
   `A` 兜底调 `B`、`B` 兜底调 `A`，遇到两边都不认识的 id 就栈溢出。
   判据：写第二个兜底之前，问「这个调用会不会转回我自己」。
   修法：加来源标记（`from_xxx: bool`），过来的那一次不再回头。

2. **`match` 的分支不 `return`，兜底又写在 match 外面**
   匹配成功的分支执行完照样往下走，撞进兜底。
   判据：兜底代码在 `match` 之后 → 几乎一定是错的。
   修法：兜底写成 `match` 的 `_:` 分支。

3. **同一个模态判断写两份（绘制一份、命中一份）**
   两份迟早不一致，表现是「面板看着盖住了，底下还能点」。
   判据：`grep` 同一个条件出现两次以上 → 抽成一个函数。

### 流程

4. **把动作延后，却没有在原来的路径上加闸门**
   M144 把「进房间」延后到玩家点击，结果玩家能直接走去下一间，
   那间房被永久跳过。**延后的动作 = 没执行**，除非原入口被挡住。

5. **清状态靠「稍后某个钩子会来收拾」**
   `_exp_persist` 里有 `if ended: 清快照`，但结算走的是 `settle()`，
   根本不经过它 → 刷奖励漏洞。清状态要写在**改变状态的那个函数里**。

6. **加字段只加内存、忘了存档往返**
   新字段进了 `to_save_dict` 却没进 `from_save_dict`（或反过来），
   读档后行为漂移，而且只在「存档 → 读档」这条路上出现。

### 界面

7. **字号是全局常量**
   改一颗会牵动所有按旧字号手算的坐标。放大后必须**逐屏截图**看，
   单测不查像素。M138 一次放大就露出 4 处溢出。

8. **手算坐标时，`_text` 的 x 是左边界**（右对齐要 `x = 右 - w`），
   **按钮文案要按最窄的那一档数字数**（M142「（全队 +20 压力）」被切掉「压力」）。

8b. **`_text()` 不传宽度 = 单行不换行，会一路画出框外**（M152）。
   凡是「内容可能长」的文字（玩家名、日志行、描述）都要显式给宽度。
   用户的规则：**宁可另起一行，也不截断**；框装不下就扩框或减字。

8c. **批量改「底部按钮 y」要 grep 所有同义变量**（M165）：
   `by` / `back_y` / `btn_y` / `dock_y` 各写各的，按一个名字替换必然漏。
   漏掉的那处表现是「按钮和底栏叠在一起」，而单测完全不查坐标。

9. **验收参数走的路和真实点击不是同一条**
   `--click=` 直接调 `_activate`，绕过 `_hit_id_at`。
   遮挡 / 穿透 / 点哪儿算谁这类问题**只能用 `--tap=x,y`** 测。

### 环境与命令

10. **找 SDK / 工具链先读 Godot 的 `editor_settings-4.x.tres`**
    真正的路径在那里（`export/android/android_sdk_path`），
    翻 `D:/Apps`、`LOCALAPPDATA` 半天找不到是白费的。

11. **新增 `class_name` 文件 → 先 `--editor --quit` 重建类缓存**，
    报 `Nonexistent function 'new'` 不是语法错。

12. **批量改名之后 `grep` 新名字**：改名脚本会把自己那一行也换掉，
    编译能过、单测能过，只在特定路径上无限递归。

### 数据

13. **判据先量数据**，别拍脑袋估（`limit` 分布、槽位 5/5/3 都是估错的）。
14. **旧文档写的「数据没有 X」也要复核**（M26 断言缺目标数量，其实一直在）。
15. **GDScript 的 `a or b` 返回 bool**，不是「a 为空就用 b」（M167）。
    `(d.get("levels") or [{}])[0]` 会得到 `(bool)[0]`，报
    「Invalid access to property or key '0' on a base object of type 'bool'」。
    要默认值就写 `x if cond else y`。
16. **数据字段的类型不能靠猜**：`heal` 是**数组** `[2,3]` 不是数字（M167）。
    写「遍历所有技能验证分类」这种全量脚本之前，先 `print` 一个样本的 keys 和值。
17. **改了一个「顺序 / 状态」的数据源，要同时问：渲染是不是也读这个源？**（M174）
    拖拽改的是 `_prep_party`，列表渲染读的是 `hero_ids_deployed_first()` ——
    两套顺序不相干，于是「号位变了、列表没动」。
17b. **同上：删了一条记录，要同时问：别处还有没有引用它？**（M177）
    解雇只删了 `roster` 里那条，`_prep_party` 还留着他的 id ——
    出征按名单拉人会拉到一个不存在的人。
    两份互相引用的数据，改一份就是脏数据。
18. **搬状态显示要对着原实现的完整分支逐条抄**（M174）。
    五档只抄了四档，漏掉 `else`（「空闲」）—— 而那恰是**大多数人的状态**。
19. **地图层 `_map_layer` 是子节点，永远画在 `self` 之上**（M180）。
    任何「要盖住地图」的面板（补给/确认框/结算）都必须
    `_map_layer.hide()`，光把背景画成不透明没用。
20. **改了「什么时候重绘」之后，要 grep 同一段里还有没有别的 `queue_redraw()`**（M183）。
    M176 加了「hover 变了才重绘」，底下 20 行处还有一句**无条件**的
    `queue_redraw()`，把优化整个抵消 —— 表现还是「很卡」，而代码看起来明明改对了。
21. **手机没有 hover**。凡是依赖悬停的交互（tooltip / 高亮提示）
    都要另给一套触摸方案（长按 / 单击选中），不能只做桌面。
22. **有图标的地方就画图标**（用户长期要求，M184 明确提出）。
    弹窗、确认框、浮层这些「后加的界面」最容易漏 ——
    主界面画了图标，弹窗里只剩一行字，玩家得靠字去认物品。
    新增任何弹窗时，第一件事是问：这里的东西有没有现成图标。

## 5. 交付前对照表（怎么验）

> 上面那张管「怎么写」，这张管「**凭什么说它能用**」。
> 这一串问题里，有一半不是代码写错，是**验证方式不对就交付了**。

1. **改界面 → 自己截图看**。
   「逻辑清楚」不是证据。M138 字号一放大，4 处溢出全是截图看出来的，
   单测一条都没报。截完再看一眼，别直接打包发人。

2. **改流程 → 走完整条路**。
   M144 把「进房间」延后，我只验了「走到门口」，没验「门口能不能走下一间」——
   结果玩家能跳过整间房。**改动碰到状态推进，就要从入口走到出口**，
   不能只验中间那一段。

3. **崩溃 → 先抓日志 / 先复现，再猜**。
   连续三轮猜错（内存 → 返回键 → 真实原因），最后是**用户截图标题写着 DEBUG、
   是桌面窗口**才想到本地能直接复现，一跑就是 `Stack overflow`。
   **有堆栈就别推理**。

4. **验证方式要和问题类型匹配**：

   | 问题类型 | 错误的验法 | 正确的验法 |
   |---|---|---|
   | 遮挡 / 穿透 / 点哪儿算谁 | `--click=<id>` | `--tap=x,y` |
   | 排版 / 溢出 / 重叠 | 单测 | 截图 |
   | 数值 / 流程 / 存档 | 截图 | 单测 + 存档往返 |
   | 真机行为（触屏、切后台） | 桌面窗口 | 打 APK 装机 |

5. **「应该没问题」是危险信号**。
   说这句话之前，问自己：**我刚才看的是哪一条输出？** 
   说不出具体命令 / 截图 / 断言，就是没验。

6. **测试全绿 ≠ 功能对**。
   1148 条断言过了，玩家还是能随便走房间 —— 断言只覆盖规则层，
   界面流程和手感它管不到。

7. **改全局常量 → 全屏扫一遍**。
   字号、边距、颜色这类被到处引用的值，改完至少把
   城镇 / 地图 / 战斗 / 名册 / 公会 / 建筑各截一张。

8. **打包前先跑一次真实入口**。
   `--start` 走到地图、点一次按钮、进一次战斗。不是为了看功能，
   是为了确认「它至少能起来」。

9. **「回滚」= 恢复到能工作的状态，不是删掉新加的那几行**。
   M150 回滚技能数值时删了调用、留着函数定义 —— 下一轮调试时
   那个函数连 `print` 都不打，白找了三版。
   回滚后 `grep` 一下函数名：**只剩定义、没有调用**就是没接上。

10. **连改三版还没看出来的，先停下来加打印**。
    不要继续猜「这次应该对了」。M150/M151 合计四版，
    最后一行 `print(lv.keys())` 一秒定位：数据一直是好的，
    问题在「函数没被调用」。
