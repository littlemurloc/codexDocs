## M32 分区任务板与任务目标层（同日继续）

**起点**：`dd_db.gd` 里根本没有 `quests` 字段——6 种任务类型、48 个目标定义
从 M0 抽出来一次没读过；任务在代码里只是 `explore` / `kill_boss` 两个字符串；
`campaign.board` 一块，四区共用。

**先做数据核查，推翻 M26 的一个结论**：M26 记的是「cleanse/gather 只有布局、
缺目标数量」——**错**。数量在 `data.amount`（gather item.amount=3）、
比例在 `data.percentage`（battle_all_rooms=1、explore_all_rooms=0.9）。
没读那两行就下了结论。

**清剿 = 探索 + 一场仗**：四个区域 × 三个尺寸，`total_room_battles` 全部差 +1
（short 1-3→2-4、medium 3-4→4-5、long 7→8），hallway_battle 完全一样。
所以清剿不是「更凶的图」，是同图多一场不能跳过的仗。

**做了什么**
1. 新增 `src/core/quest_goal.gd`（~200 行）：`parse(quests, quest_type, region)` /
   `met(goal, state)` / `progress` / `describe`。不认识 Expedition 也不认识界面，
   状态由调用方拼扁平字典（`at_goal`/`boss_killed`/`battles_total`/`battles_cleared`/...）。
2. `DdDb.quests` 接上（`_read_dict_fallback`，不走 balance 包）。
3. `Campaign`：`boards`（region→4 格）+ `BOARD_SLOTS_BY_REGION` 四区槽位不同；
   `board` 保留为 `boards[board_region]` 的**同名引用**（不是复制）；
   `select_board_region()` / `board_for()` / `_sanitize_board()`。
   保底档是**区域级**的（每块板子都有一格）。
4. `Expedition`：`quest_goal` / `quest_state()` / `quest_met()` / `quest_line()`；
   `enter_map` 固定分母（`quest_battles_total`）；`finish_battle` 只数 room/boss 且非僵持；
   `_end("complete")` 过通用判据（路线模式不参与，保 M3 基线）。
5. 界面：区域按钮同时切板子；卡头 `清剿 · 短途 · 1 级怪`；地图右面板加任务行；
   打过战斗房变暗；出口房未达成时警告。
6. 自检 AI 学会绕路：`_pick_step` / `_nearest_uncleared_battle` / `_step_toward_room`
   （以当前房间为源 BFS，能往回走）。

**数值**：清剿短图 Lv1 ×10 —— AI 只会朝出口走时 **0/10**；学会绕路后 **9/10**，
推进 5/7→6/7 房间，出手次数 20-65 → 40-97（翻倍，这就是清剿收的税）。
探索仍 10/10。

**最大的发现（数据缺口）**：10 个任务奇物里 **9 个在 `_raw` 出现 0 次**
（reliquary / chirurgeons_satchel / foodstuff_crate / shipment_crates /
corrupted_altar / infected_corpse / animalistic_shrine / protective_ward / beacon），
只有 `iron_maiden` 真的存在。所以 gather/activate 不是「没时间」，是**目标不存在**。
下一步应做「奇物标签化」的目标表，而不是硬映射。

**验证**：1172 项断言全绿（+68，新增 `tests/test_m32.gd`）；
自检 explore PASS / cleanse 9/10；截图 `shots/m32_{town_weald,town_cove,town_click,map_cleanse}.png`；
文档 `M32_TASK_BOARD.md` 十节；README 同步（断言数、结构、限制、重跑命令）。
未 commit、未 push。

**踩的四个坑**： board 必须是同一个数组（复制会出现「换区域再换回来选择没了」）；
旧档迁移不能走 `roll_board()`（会整本重抽＝刷任务）；分母必须进门时固定
（边打边数永远 100%）；任务行不能放顶部状态条（1080 宽和「侦察」重叠）。

## M33 任务奇物标签化 + 收集 / 激活

**起点**：M32 查出 10 个任务奇物里 9 个在 `_raw` 出现 0 次。硬编 id 冒充＝假造数据，
所以把目标**降到标签层**：`CURIO_TAG_MAP`（10 条，每条带 why）
+ `resolve_curio(name, region, curios)`：
1) 名字本身是真的且区域对得上 → 直接用（只有 `iron_maiden`）；
2) 否则查标签，在该区域带该标签的奇物里取，**本区域优先于 ALL**，同层按 id 排序。
确定性：同 (名字, 区域) 永远同一 id，否则同一张卡每次指的东西不一样。

**地图投放**：gather/activate 的图自然只有 1–2 个随机奇物，不管的话收集必做不完
（而「做不完」不报错，只像运气差）。`MapGen._place_quest_curios` 在常规内容之后
按 `amount` 额外投：空房间优先 → 空走廊兜底，避开入口/终点，用**派生 rng**
（`need*101+7`），step 打 `quest:true` 标记。房间数不变。

**计数**：`Expedition._note_quest_curio` —— 只算目标奇物、**不看交互结果**、
去重键是**位置**（`room:N` / `edge:N`）。`travel()` 里给房间步补 `room` 键。

**任务板**：四区槽位改成 探索/清剿/收集/激活/首领 的混编。
硬约束：收集/激活在 dungeons.json 里**只有 medium 一档**，且 activate 目标
铁处女只在墓穴 → 这两种只能放对应位置。

**数值**：收集（荒野 medium Lv1）×5 → 4 次完成、收集=3；
激活（墓穴 medium Lv1）×5 → 5 次完成。探索/清剿回归 PASS。

**踩的三个坑**
1. 去重键写成奇物 id → 任务要 3 件、图上 3 个同类奇物，碰完第一个后
   另外两个全被挡掉，**收集数永远停在 1**。按位置改才到 3。
2. 测试用「图里有没有这个 id」判投放 → 探索图也会自然刷同一个奇物，随机红。
   改成数 `step.quest` 标记。
3. 奇物房只写「奇物房」→ 玩家找「老树」得一间间进。加 `_room_label()`，
   奇物房直接报名（原版靠精灵图认，我们没美术，名字是等价物）。

**验证**：1210 项断言全绿（+38，新增 `tests/test_m33.gd`）；
截图 `shots/m33_{town_weald,map_gather,map_gather_progress}.png`；
文档 `M33_QUEST_CURIOS.md` 九节；README 同步。未 commit、未 push。

**下一步建议**：同职业多人（roster 的 key 从职业 id 改 uid）——它是加法之外
的**改地基**，名册/存档/任务板/招募/解雇全要动，越晚越贵。
道具系统（解锁 inventory_activate）是另一条路，但那是加法。



## DD1 客户端资源盘点（核查结论）

源：`/d/Program Files (x86)/Steam/steamapps/common/DarkestDungeon`（Steam 262060，2.7G）。
**本体齐、DLC 缺**：15 英雄（无 shieldbreaker）、101 怪物、6 地下城（无 courtyard / farmstead）、
12 语言含 schinese、3 段 .ogv 过场、30 个多页位图字体（中文 SimSun 45px × 38 页 TGA，**无 ttf/otf**）、
5274 png（1210 张 anim 图集页 + 3772 张单图）、1369 skel + 1369 atlas、41 个 FMOD Designer bank（610M）。

**不能直接拿来用（三条硬门槛）**：
1. 骨骼是 **Spine 2.1.27**（2015），spine-godot 只支持 3.8/4.x，Godot 4.4 无兼容 runtime；
   只能离线烘序列帧或自写 2.1 解析器，且 Spine runtime 需商业授权。
2. 音频是 **FMOD Designer 4.x（RIFF/FEV FMT）**，不是 FSB5，现代 FMOD Studio 不读；
   需 fsbext 类工具解 FSB→wav，事件逻辑（随机变体/参数混合）要在 Godot 重建。
3. 图集页是拼合大图（如 2015×1186），必须按 .atlas 坐标切；字体是位图，不可缩放。

**可直接用（零改造）**：.ogv 过场、panels/icons/cursors/loading_screen 单图、
dungeons/* 的 corridor_wall/corridor_bg/door 可平铺贴图。
