# M48 · 删除存档、阵亡记录、主菜单背景

> 三件「用了才会发现缺」的东西。

## 1. 删除存档

### 交互

存档卡右上角一个「删除」，点了之后卡片原地变成确认态：

```
删除后不可恢复 —— 这一档的全部进度会消失
[ 确定删除 ]  [ 取消 ]
```

原地确认而不是弹窗：弹窗要处理层级、点击穿透、ESC 关闭，而这一屏只有三个卡，
原地替换信息量一样、代码只有几行。

### 一个必须注意的顺序

```gdscript
_add_button(删除按钮)          # 先
_add_hit(整张卡, "slot:%d")    # 后
```

`_on_click` 是**按加入顺序**匹配的，先命中的赢。卡片本身就是「点这里读档」的大热区，
删除按钮如果后加，会被卡片整个吃掉——点了删除，结果是**直接进了那个档**。

### 实现

```gdscript
var dir := DirAccess.open("user://")
if dir != null and dir.file_exists(fname):
    dir.remove(fname)
```

只删那一个文件，另外两个槽不受影响（三个独立文件）。

## 2. 阵亡记录

### 之前

名册里只有 `deaths` 计数。墓园屏自己写着「谁死在哪一趟、什么原因，需要结算时落盘，还没做」。

数字没法回看，墓园就成了计数器——而它存在的意义就是让人回看。

### 现在

```gdscript
campaign.death_log: Array   # [{hero, week, region, size, level, reason}, ...]
```

- 在 `settle()` 里写入，**周数取 `advance_week` 之前的值**（人是在这一周死的）
- 上限 **240 条**（15 职业 × 16 次）。不设限的话一趟全灭加 4 条，200 趟就是 800 条
- `from_dict` 对旧档没有该字段的情况返回空数组，老存档照常能读

墓园屏每行现在是两行：

```
十字军        阵亡 1 次 · 出征 0 次 · 未归队
              最近：第 12 周 · 荒野 · 短途 1 级 · 全队覆没
```

一句话的字段顺序按**玩家的选择顺序**排：什么时候去 → 去哪 → 打多难 → 结果。

### 验证

跑一趟 `--level=5 --size=long`（Lv1 队伍打冠军长途），全队覆没，`death_log` 写入 4 条：

```json
{"hero": "crusader", "week": 1, "region": "weald", "size": "long", "level": 5, "reason": "wipe"}
```

同时 `[econ] 结束=wipe 战利品 1300 + 任务奖励 0`——wipe 不发任务奖励，判据和 `xp_for` 一致。

## 3. 主菜单背景

### 两张图，不是一张

| 文件 | 来源 | 作用 |
|---|---|---|
| `assets/art/ui/menu/bg.png` | `fe_flow/title_bg.png` 底部区域 | 红色余烬，占满全屏 |
| `assets/art/ui/menu/house.png` | `fe_flow/title_house.png` | 庄园剪影（透明底） |

分开存的好处：换风格时只换其中一张，比如把庄园换成别的建筑。

### 三次调参才成立

**第一次**：直接用原图，庄园的**下半部分是 alpha=255 的纯黑**，叠在红色底图上露出一条水平硬边，像贴了一张纸。

**第二次**：裁掉底部实心黑 + 底部 120px 透明渐隐。硬边没了，但**红色亮成一片探照灯**——`gamma 1.75` 压不掉纯红（R 通道本来就到 255），得同时降亮度到 0.42。

**第三次**：庄园的地形边缘在红光上仍然显成一条线。把渐隐起点提到 270、范围拉到 200px 才融进黑暗。

### 压暗是分两段的

标题和副标题在 0–190，庄园的塔楼正好也在那儿。用一条连续曲线的情况下，压到副标题那一行只剩 0.3，字是清楚的、**背后有碎石纹理穿过来**。

改成：0–160 直接压到 0.86，160–240 再渐隐回背景。

### 退路

```gdscript
if not _draw_menu_bg():
    # 16 段线性渐变的纯色 Background
```

`--no-skin` 或"图没导入"都走这条路。**主菜单是第一屏，它挂了整局都进不去**，退路必须有。

## 5. 已知限制

1. **删除没有「撤销」**。二次确认是唯一的保护。要真做撤销得把文件移到临时位置保留一段时间，收益不值。
2. **阵亡记录没有分页**。240 条全塞在一屏里会溢出面板，现在只显示最近的（`graveyard()` 按次数排序，每行两行文字）。真要翻页是另一件事。
3. **主菜单背景是 Red Hook 的原画**，只能本地用、不进版本库（`.gitignore` 的 `assets/art/ui/**/*.png` 已覆盖）。
