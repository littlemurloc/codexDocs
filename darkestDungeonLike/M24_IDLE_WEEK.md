# M24 · 主动过一周

> 一句话：M23 让「一趟 = 一周」，但时间只能**顺便**流逝——打完一趟才走一格。
> 这一期让时间变成玩家可以主动买的东西：花 50 金，什么都不做，过一周。

## 1. 起点：时间不能主动过

M23 之后，`advance_week()` 只在一个地方被调用：`settle`。

结果是「建筑占了人」这个机制只有一半：
派一个人去疗养院，你不打一趟，他那一周就**永远不结束**。

而且副作用有个荒唐的对应关系：想让压力恢复、想让建筑队列走一格，
唯一的方法是再打一趟——而那趟又会给全队加压。

## 2. 两个必须先解决的问题

### 问题一：压力不恢复的话，「休整」是纯亏

M23 把 `weekly_stress_relief` 默认设成 0，理由是「动续航要重跑基线」。
但那样「休整一周」只能推进建筑队列和换商店货，压力一点不掉，玩家凭什么花这个时间？

所以这一期把它打开：**10 点/周**。

参照系是回城那 40 点：一周自然恢复约等于回城的四分之一。于是三条路形成梯度：

| 方式 | 压力 | 成本 | 代价 |
|---|---|---|---|
| 打一趟 | −40（回城） | 0 | 可能全灭 |
| 去酒馆 | −70 | 450 金 | 占一周 |
| 去修道院 | −40 | 200 金 | 占一周 |
| **休整一周** | **−10** | **50 金** | **没有收入** |

休整是最弱的，但它**不占用人**——你可以在同一个人身上连续休整多周。

**bench 不受影响**：`bench_expedition` 走的是 `Expedition`，不经过 `Campaign`，
所以批量的完成率/压迫指数那批数字逐位不变。这一期改的纯粹是城镇回合。

### 问题二：不收钱的话，「休整」是免费的商店刷新

`advance_week` 会 `refresh_shop()`。如果休整免费，玩家可以：

```
休整 → 看商店 → 没想要的 → 再休整 → 再看……
```

无限刷出货架。原版靠「不出发，任务难度会爬升」来堵这个洞，
我们没有难度爬升，只能用钱堵：**50 金/周**。

对照一趟 short Lv1 约 3498 金，50 金拦不住正常使用，但刷 70 次就破产。

## 3. 实现

规则层只有一个新方法：

```gdscript
func idle_week() -> String:
    var cost := int(cfg.get("town_cycle", {}).get("idle_cost", 50))
    if gold < cost:
        return "金币不足（需 %d）" % cost
    gold -= cost
    advance_week()
    return ""
```

顺带做了一次内聚修正：**商店刷新从 `settle` 移进 `advance_week`**。
原来 `settle` 里是「`advance_week()` 然后手动刷新」，现在时间推进的副作用
只有一个来源——以后再加第三种推进时间的方式（比如事件、或者「一直休整到某周」），
不会漏掉某个副作用。

界面：城镇「出发」那一行右边加一个按钮，和区域选择同排——
因为「这周出门」和「这周在家待着」是同一层的选择。

副标题也改了：`远征 10 趟 · 每周自然恢复 10 压力`。
不写这句的话，「休整一周」看起来只是浪费时间，玩家不会知道那 50 金买到了什么。

## 4. 数据

```json
"town_cycle": {
  "weekly_stress_relief": 10,
  "idle_cost": 50
}
```

两个数都写进 `note` 了，包括「为什么不收钱不行」这个理由——
半年后回来看这段配置的人，第一反应一定是「50 是不是太少了，能不能去掉」。

## 5. 测试

新增 9 条，重点不在「能跑通」，在**两个失败路径**：

- `idle_cost > 0`（否则就是免费刷新，这是设计约束不是实现细节）
- `wk_relief > 0`（否则休整纯亏）
- 钱不够时 `idle_week()` 失败，**且不推进时间**（失败不能产生副作用）
- 休整能让忙的人少忙一周（否则建筑队列还是只能靠打仗推进）
- 压力按配置恢复，不写死 10

最后一条是老规矩：数字从配置读，别把旋钮焊进测试。

## 7. 没做的

- **「一直休整到某周」**：现在一次一周。想连续休整五次要点五次。
- **休整期间的随机事件**：原版「在城里待着」会遇到事件（马车来新人、有人敲门）。
  我们什么都没有，所以休整是纯粹的「花时间换压力」。
- **难度随时间上升**：这是原版时间压力的另一半——拖得越久，敌人越强。
  我们只有「钱」这一个护栏，没有「时间」这个护栏。
- **建筑的下周生效队列**：M23 §9 提过，还没做。现在效果仍是立即的，
  所以「派出去」和「花完钱」之间没有等待感。
