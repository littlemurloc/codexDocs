# M26 · 任务板

> 一句话：M25 装上了「不让你往下走」的锁，这一期补上「把你往上赶」的力。
> 城镇那四张难度卡的等级，从写死的常量变成**每周按名册重抽**。

---

## 1. 起点：有锁，没有力

M25 之后，一个练到 3 级的英雄就被学徒本拒之门外了。听起来「难度在往上推」，
其实只推了一半——

```gdscript
var rows: Array = [
    ["short", 1, "短途 · 1 级怪", ...],
    ["medium", 3, "中程 · 3 级怪", ...],
    ["long", 5, "长途 · 5 级怪", ...],
    ["medium", 3, "首领 · 3 级怪", ...],
]
```

这段常量写在 `expedition_scene.gd` 里，**从 M0 到 M25 一直没变过**。
所以真实的处境是：锁让你进不了低难度本，但板子上永远摆着 1/3/5 三档任选，
你只要不点那张高的，就永远不会被推着走。

原版不是这样。原版的任务板**每周刷新，难度按名册加权**：

- 队伍练强了 → 刷出来的任务跟着变硬（往上赶）
- 但永远保底一张学徒本（留退路）

两件事必须一起。只做加权会锁死玩家：名册里全是高级人时，
板子上全是硬任务，新招的 1 级英雄没有任何成长路径。

---

## 2. 为什么不能照抄

原版敢写死「永远保底一张学徒本」，是因为**马车每周能补 1 级新人**——
名册是几十人，随时有低等级的人能接低难度任务。

我们只有 5 个固定 ID。全员练到 5 级时硬塞一张学徒本，得到的是：

```
短途 · 1 级怪    够格 0 人   全都超级了
中程 · 3 级怪    够格 0 人   全都超级了
长途 · 1 级怪    够格 0 人   全都超级了
首领 · 5 级怪    够格 5 人
```

四张卡里三张红的——那不是丰富度，是三个点不动的按钮。

所以这一期做了**三处有意的偏离**，都写在代码注释里：

| # | 原版 | 这里 |
|---|---|---|
| 1 | 保底「学徒本」 | 保底「**名册里最弱的那个人不用吃惩罚就能打的最高档**」 |
| 2 | 难度按名册加权随机 | 池子按「**至少一个人能进**」筛，再按强度加权 |
| 3 | 尺寸和难度独立随机 | 尺寸固定在四个槽位上（我们只有四张卡） |

第 1 条是关键。名册是 5/5/5/5/1 混编时，两种规则等价（都保底 Lv1）；
全员 5 级时，原版规则给废卡，这里给的是玩家真正需要的那个难度。

---

## 3. 规则

```
board_ceiling()   名册最高等级 + 1，归到 1/3/5
                  （+1 是为了留一个「略微超纲」的选项：
                    高 1 级只是进本吃 20 压力，不是拒绝）

board_level_pool()  1/3/5 里，名册里至少有一人能进的那些
                  名册全员 5 级 → [5]；全员 1 级 → [1]；混编 → [1,3,5]

board_floor_level() 名册最弱的人能免罚打的最高档

roll_board()      四次抽卡：随机一格放保底档，其余三格从
                  「能凑够一队（4 人）」的档里按权重抽
```

**最后一条是这一期最重要的决定**：不是「先按权重抽 4 张，再检查有没有学徒本」，
而是「一格先给最弱的人，剩下三格才谈选择」。

前者会产出 2–3 张废卡（实测 43%），后者稳定在 25%——正好一张。
差别在于**废卡有了明确的身份**：它不是抽坏的，是这一周留给新人的那个位置。

保底档落在哪一格是随机的，否则「短途」就等于「入门」，
其他三种尺寸永远拿不到低难度。

## 4. 数据（每档 300 周 × 4 张卡）

| 名册 | 等级池 | Lv1 / Lv3 / Lv5 | 凑不够 4 人的卡 |
|---|---|---|---|
| 全员 Lv1 | `[1]` | 100% / 0 / 0 | 0% |
| 全员 Lv2 | `[1,3]` | 59% / 41% / 0 | 0% |
| 全员 Lv3 | `[3]` | 0 / 100% / 0 | 0% |
| 全员 Lv5 | `[5]` | 0 / 0 / 100% | 0% |
| **4×Lv5 + 1×Lv1** | `[1,3,5]` | 25% / 0 / 75% | **25%** |
| 2×Lv5 + 3×Lv3 | `[3,5]` | 0 / 25% / 75% | 25% |

三件事：

1. **名册等级一致时板子也一致**（前三行 100%）。这不是 bug，是「名册决定板子」
   的直接结果——而它反过来给了玩家一个动机去保持等级梯队。
2. **混编名册的废卡率正好 25%**，也就是四张里一张，且一定是保底那张。
3. 全员 Lv2 能同时看到 Lv1 和 Lv3（46/54），因为 `ceiling + 1` 把 3 级放进了池子。
   不给这个口子的话，2 级名册的板子会永远只有学徒本，玩家没有任何理由再练一级。

---

## 5. 踩的两个坑

**（1）第一版保底逻辑写成了「事后检查」**

按权重抽完 4 张，再检查有没有 Lv1，没有就把第一张改成 Lv1。
结果混编名册的废卡率是 **43%**——因为 4 个 Lv5 的老人把 Lv1 和 Lv3 都挤成了废卡，
而事后的补丁只修一张。

改成「先定保底槽，再从能凑够一队的档里抽剩下三格」，废卡率掉到 25%。

**（2）`board_ceiling` 一开始没有 +1**

全员 Lv2 的池子是 `[1]`——2 级的人打学徒本正合适，但板子上永远只有这一档，
练到 2 级之后玩家看不到任何新东西。

加了一级之后变成 `[1,3]`：3 级本对 2 级人是「进本吃 20 压力」，
不是拒绝。这 20 点压力就是原版用来催人往上走的那个甜点。

---

## 6. 已知限制

1. **名册不能扩到 5 人以上**（M25 就记着的那条）。这是本期的所有妥协的根源：
   保底不敢写死学徒本、废卡率压不到 0，全是因为「只有 5 个人、死了重招就是 1 级」。
   原版的整套节奏建立在「几十人名册 + 每周补新人」上。
2. **尺寸和难度还是绑在槽位上**。原版是「尺寸 × 难度 × 区域」三维随机，
   我们四张卡的尺寸固定（短/中/长/首领），只有等级在变。
3. **没有任务目标的变化**。`cleanse` / `gather` / `activate` 三类任务的数据
   早就抽出来了，但一直没接（M20 起就记着），所以板子上只有 `explore` 和 `kill_boss`。
4. **板子不按区域刷新**。原版每个区域有自己的任务板；我们是四个区域共用一块，
   区域只影响遭遇表（M20）。

## 8. 下一步

难度这条线到这一期算是闭环了：

```
数据（遭遇表按等级分档）      ← M7
等级锁（不让你回头）          ← M25
任务板（把你往上赶）          ← M26
```

剩下三块都在“名册”上，而且互相咬：

1. **名册扩容**（马车每周来新人）—— 解开 §6 所有妥协的前提。
   做完之后，保底可以真的写死学徒本，废卡率能压到 0。
2. **受压 +25%/级**（M25 留下的另一半）。单独一期，带基线对照。
3. **区域各自的任务板**。现在四个区域共用一块板子，而区域差异只体现在遭遇表上；
   原版是每个区域一套任务，玩家按「我想打哪个区域的怪」来选。

我倾向 **1**：它是本期所有妥协的根，做完之后回头看这段代码会更简单，
而不是更复杂。
