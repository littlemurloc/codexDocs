# M47 · 主菜单、存档槽与设置

> 启动不再直接进城镇。这一期把「像个 demo」的最后两处补上。

## 1. 主菜单与三个存档槽

### 之前的状态

- 启动 → 直接进城镇
- 换档只能靠命令行 `--save=xxx.json`
- 想开第二档？自己记住路径

### 现在

```
空 腔
带四个人下去，把能带的都带回来

[ 存档 1 ]  第 12 周 · 37 趟 · 名册 9 人（活 7）
            金币 8400 · 首领 2 / 4
[ 存档 2 ]  第 1 周 · 0 趟 · 名册 5 人（活 5）
            金币 0
[ 存档 3 ]  空 —— 点这里开始新的一档

        [ 设置 ]  [ 退出游戏 ]
```

- 槽位文件：`user://save_1.json` / `save_2.json` / `save_3.json`
- **空槽不走特判**：`load_or_new()` 发现没有文件就开新档并立刻存，
  所以「点空槽 = 新开一档」是免费得到的，不需要两条分支各写一遍
- 「文件在但读不出来」显示成 **损坏**，不是空。显示成空会让玩家以为档没了，
  然后点进去被覆盖——那才是真的没了

### 主菜单什么时候出现

判据是**「这次运行是不是人手动打开的」**：

```
--start / --auto / --selftest / --to-result
--prep / --guild / --bld= / --victory
--save=（非默认路径）
```

任何一条命中就跳过菜单。逐条列而不是「有参数就跳过」——
`--w` / `--dev` / `--mute` 这些纯调试开关不影响流程，加了它们也该看到主菜单。

> **对截图脚本的影响**：`--shot=xxx` 单独用现在截到的是主菜单。
> 要截城镇得带 `--save=user://xxx.json` 或 `--click=slot:0`。

### 一处重构

`_ready` 里那段「建 Campaign + 读档 + 挂库」抽成了 `_boot_campaign(path)`。

原因很实际：主菜单要先让玩家选槽，选完才知道读哪个文件，
而这段初始化原来写死在 `_ready` 里，**没有「稍后再调一次」的入口**。

## 2. 设置：只有主音量

### 为什么只有一项

分辨率和全屏做不了：项目把 viewport 定死 1280×760，改窗口只是缩放内容。
做出来会是三个不起作用的按钮，**比没有更糟**。

主音量是唯一一个「不改就真的影响体验」的项——之前写死 `-7dB`，
在笔电外放上偏吵、在耳机上偏轻，两边都不合适。

### 映射不是线性的

```gdscript
func _volume_db(v: int) -> float:
    if v <= 0: return -80.0
    return lerpf(-34.0, 0.0, float(v) / 100.0)
```

- **线性百分比直通 dB 是错的**：人对响度的感知是对数的，线性映射会让
  0–70 这一段几乎没有变化、70–100 突然变响
- **0 单独给 -80dB**（等于静音），而不是 -36dB——-36 还能听见一点，那不叫关掉

### 存在哪

`user://settings.json`，**和存档分开**。

设置是「这台机器」的，存档是「这一档」的。混在一起会出现「换个槽音量就变了」。

读写都不报错：文件丢了 / 损坏就用默认值。设置丢了的后果是「音量回到默认」，
不是「游戏打不开」。

### 调音要能听到

点任何一个音量格立即播一声 click。调音量时听不到声音等于盲调。

## 3. 踩的坑

### 3.1 背景用两段矩形画渐变

第一版：

```gdscript
draw_rect(整屏, 亮色)
draw_rect(下半屏, 暗色)
```

结果画面上一条横贯的水平分界，像被切了一刀。

CanvasItem 没有渐变填充，只能多段矩形逼近。改成 16 段线性插值。

### 3.2 右对齐又一次

见 M46 §3.1。这期新加的三处右对齐一开始也写错了，
所以那条约定值得单独记：**`pos.x` 永远是文本框左边界。**

### 3.3 `--w` 在主菜单上没生效

`_want_w` 的应用在 `_boot_campaign` 之后，而菜单分支在那之前就 `return`。
1080 宽下截主菜单，出来还是 1280。

同一个坑 M41 踩过（`--resolution` 不改变视口）。**「测了但没测到」比没测更危险**，
因为报告会写「已验证 1080」。

## 5. 已知限制

1. **没有删除存档**。要删只能去文件夹里删文件。加「删除」得先做二次确认，
   而这一期的重点是「能用」，不是「完整」。记在这里。
2. **槽位数量写死 3**（`SAVE_SLOTS`）。改成一个数就能变，但没有做「更多槽」的 UI。
3. **设置只有音量**。见 §2 的理由。
4. **主菜单没有背景插画**。用的是一层暗渐变。要加的话 DD1 的 `fe_flow/` 下有 1920×1080 的标题图，
   但那些是 Red Hook 的原画（版权图），只能本地用、不入库——和战斗背景同一处理方式。
