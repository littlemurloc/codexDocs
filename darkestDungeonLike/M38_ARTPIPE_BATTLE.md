# M38 · 战斗屏站桩：从「卡片」到「人站在地上」

> 一句话：用户带来的那批导出帧把 M36 的判断推翻了——**DD1 有立绘，只是不在安装目录里**。
> 于是战斗屏从两排卡片换成了两排站桩，并且**出招会换帧**，用的是数据里现成的映射。

---

## 1. 素材：这次是真的完整帧

M36 我查的是安装目录：`heroes/<id>/anim/*.sprite.combat.png` 是 **atlas 零件页**，
`.atlas` 里的 `offset` 全是 `0,0`（裁剪信息，不含摆放），不解析 `.skel` 拼不回来。

用户提供的 `DD sprites-…zip` 是**别人用 Spine 导出好的成品帧**：每张一个完整角色，
RGBA 真透明，画布紧贴人物。两者不矛盾，是**来源不同**。

| 维度 | 实际 |
|---|---|
| 职业 | 18（本作 15 全齐 + Shieldbreaker / Flagellant / Musketeer） |
| 配色变体 | 每职业 4 套 |
| 动作 | 65 种，含 `combat` `dead` `defend` 与**每技能一个 `attack_*`** |
| 画布 | 内容高 546–788，脚底在画布底边 |
| 陷阱 | `afflicted` / `heroic` 是 **2000×2000 的全屏插图**，不是战斗姿势 |

## 2. 关键发现：技能 → 帧的映射是数据现成的

`data/heroes.json` 里每个技能都带 `art.anim`：

```json
{"id": "smite", "art": {"anim": "attack_sword", "icon": "one"}}
```

素材包里正好有 `crusader.sprite.attack_sword.png`。**15 职业 × 全部技能，一张不缺**
（只有 `hellion` 缺 `afflicted`，她本来就没这个动画）。

所以「出招换帧」不需要手工建表，也不需要改规则层——战斗事件的 `attack` 已经带了
`skill` 字段，查一次 `art.anim` 就能定位姿势。

运行时验证（`--dev` 会打印）：

```
[pose] highwayman 用 wicked_slice -> attack_slice
[pose] plague_doctor 用 plague_grenade -> attack_grenade
[pose] crusader 用 smite -> attack_sword
[pose] vestal 用 judgement -> attack_lectionary
[pose] cultist_witch_A/cultist_incantation 没有对应动作帧   ← 怪物，符合预期
```

## 3. 导出与槽位

只导出**战斗需要的四种**：`combat` / `dead` / `defend` / `attack_*`，共 **121 张 / 13 MB**。

```
assets/art/units/<id>.png            方形头像（UI）
assets/art/units/<id>_<anim>.png     动作帧
```

### 归一化基准：人物本体高，不是画布高

第一版按**画布高**归一（所有帧统一到 400 画布高），出图后立刻被指出问题：
**十字军明显比其他人矮一截**。

原因查出来了——它的 `combat` 帧举着一把很长的剑，剑尖把画布撑高了 26%：

| 职业 | 画布 | 头顶所在行 | 本体占画布 |
|---|---|---|---|
| **crusader** | 307×789 | 209 | **74%** |
| 其余 14 个 | — | 3–60 | 93–99% |

按画布归一 = **把剑的长度也算进身高**，于是剑越长人越矮。

改成按**本体高**归一：从图片顶部往下扫，找第一个「有效像素宽度 ≥ 最大宽 16%」的行
当头顶（跳过剑尖、旗杆这类细长物），`k = 400 / 本体高`，同一职业的所有帧共用这个 `k`。

改完 15 个职业的 `k` 落在 0.568–0.746，十字军从 0.507 提到 0.69——**头顶终于齐了**
（对比 `shots/m38_battle_stub.png` 前后两版）。

绘制端因此只有一个全局 scale（`SPRITE_H / 400`，即「人 180px 高」），
脚底统一压在地面线上；剑该伸多长就伸多长，不受身高基准影响。

## 5. 没有美术的怪物：兜帽剪影

这批素材只有英雄。怪物仍然没有静态图（安装目录里它们是 Spine 骨骼）。

第一版画的是「阵营色圆牌 + 名字首字」，出图后问题很明显：**写实立绘旁边摆四个空圆牌**，
一半是画、一半是图标，比全占位更刺眼。

现在改成程序化剪影：头（圆）+ 袍子（多边形）+ 两点眼睛。缩到 180px 后有头肩分界，
读得出「一个人形站在那儿」。**死了就塌成一堆**（高度 ×0.36），因为站着的剪影变灰
读不出「它已经死了」。

将来 AI 出同规格怪物图，把 `<monster_id>_combat.png` 放进同一个目录即可，
代码一行不用改——`UnitArt.frame()` 只认文件名。

## 6. 踩的四个坑

1. **交战线穿过了英雄**。第一版取两条地面线的中点（365），而那个高度正好是我方
   立绘的头部区间。改成取「敌脚 250」和「我头顶 300」的中点。

2. **压力文字被日志面板压住**。立绘脚在 480，压力文字 517，面板从 516 开始。
   面板下移到 530，高度从 230 压到 206。

3. **「阵亡」标记落进相邻一排的头顶**。敌方标记画在 `gy+38 = 288`，
   而我方立绘从 300 开始——截图里一度被误读成「十字军死了」，其实它还有 22/33 血。
   现在**两边都不写「阵亡」**：我方是躺倒的 `dead` 帧、敌方是塌掉的剪影，图形已经说明。

4. **选中环盖住血条**。正圆半径 46 会横穿脚下血条。改成压扁的地环（y 缩放 0.26）。

5. **按画布高归一，把人算矮了**。用户看图后一句「缩放比例以人物的脑袋对齐比较合理」，
   查出来是归一化基准选错：`crusader` 的 `combat` 帧举着长剑，画布 26% 是空的，
   按画布归一等于把剑算进身高。改成按「脚底到头顶」归一后，15 个职业头顶齐平。
   **这条是本轮最值钱的修正**——它不影响任何逻辑，但决定了所有人看起来是不是一伙的。
