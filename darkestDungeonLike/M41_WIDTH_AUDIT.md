# M41 · 1080 宽排版验收

> 一句话：**1280 下"刚好"的布局，到 1080 会出界。**这一期把两个屏都过了一遍。

---

## 1. 先说工具：`--resolution` 没用

第一反应是 `--resolution 1080x760` 启动，截出来还是 **1280×760**——
项目把 `window/size/viewport_width` 定成 1280，且没设 stretch 模式，
内容尺寸不跟窗口走，等于**测了个假的**。

改用新参数 `--w=N`：在 `_ready` 末尾设 `get_window().size`，
并且**截图时打印实际布局宽**：

```
截图已保存：shots/m41_town_1080.png（布局宽 1080）
```

打印这一行不是啰嗦——没有它，我第二次还会以为在测 1080。

## 2. 战斗屏：敌方第 4 格直接出屏

`enemy_x0 = party_x0 + SLOT_W * 3 + 20`，`SLOT_W` 写死 170：

| 视口 | 敌方 rank4 右边缘 | 结果 |
|---|---|---|
| 1280 | 1250 | 刚好 |
| **1080** | **1250** | **出屏 170px** |

而且**平时看不出来**——遭遇表多数是 3 只怪，第 4 格空着。

改成每格宽度跟视口走：

```gdscript
var slot: float = clampf((size.x - 80.0) / 7.0, 120.0, 176.0)
```

1280 → 171（和原来的 170 基本一致，视觉不变），1080 → 143（四只怪都在画面内）。

顺带两处跟着自适应：

- **名字宽度**原来写死 160，1080 下比格子（143）还宽，会和邻居压在一起
- **技能按钮副标题**原来不截断，1080 下按钮只有 144 宽，
  「修正 +15% · 命中 +85% · 敌 · 效…」直接溢出到隔壁那一列上 → 加 `ellipsis`

## 3. 状态标记压在日志面板上沿

`DOT×1` 画在 `gy + 50`，而我方地面线是 480 → 530 = **日志面板的顶边**。
1280 下勉强能看见（文字压在面板上），1080 下更明显。

两处一起调：地面线 480 → **470**，标记 50 → **47**，落点 517 < 530。

## 4. 城镇屏：建筑卡文字贴到卡片下沿

底条 34px、文字在 `bh-16` / `bh-3`——第二行离卡片边只剩 3px，1080 下看起来像被切掉。

改成底条 40px、文字 `bh-22` / `bh-6`，图高 `bh-42`。

英雄卡在 1080 下只有 119 宽（1280 是 146），头像 36 → **32**、文字列 50 → **46**，
勉强放得下「瘟疫医生」四个字。

## 5. 验收结论

两屏在 1280 与 1080 下都不再出界、不重叠。**但 1080 是下限，不是舒适区**：

| 屏 | 1280 | 1080 |
|---|---|---|
| 城镇 | 宽松 | 挤（8 张卡 119 宽，字号已到最小值） |
| 战斗 | 舒适 | 立绘互相压（格子 143，最宽的单位 188） |

**一个没修的问题**：1080 下我方立绘会轻微互相遮挡。格子 143 而
`houndmaster` 这类带宠物的立绘缩放后宽 188——要么缩图（会破坏"头齐"），
要么接受遮挡（DD1 里前后排本来也遮）。这一期选择接受，记在这里。

**建议**：如果要支持 1080，城镇的 8 张建筑卡应该改成 4×2 两行，
而不是把 119 宽硬撑。那是 b 档的事。
