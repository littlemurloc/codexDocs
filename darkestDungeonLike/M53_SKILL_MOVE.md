# M53 出手时的人物位移

> 你说「原版有些角色攻击时会位移，我们这版好像没看到」。
> 查下来不是「做得不明显」，是**根本没有发生**——数据里有字段，规则层从来没读它。

---

## 1. 根因：字段存在，但没人用

`data/heroes.json` 里每个技能都有 `move`：

```json
{"id": "point_blank_shot", "move": [1, 0], "effect": "Push 1A"}   // 强盗：开完枪退 1
{"id": "holy_lance",       "move": [0, 1]}                        // 十字军：圣枪突进
{"id": "heroic_end",       "move": [3, 0]}                        // 小丑：收场后退到队尾
```

这个字段从 M0 就解析进了动作字典（`combatant.gd` 的 `build_actions`，第 273 行），
然后**再没有任何一处读过它**。全项目 grep `get("move")` 只命中两处，都是
「每回合一次的免费调整站位」（`move_action`），不是技能自带的位移。

所以卡片上的 rank 变化一直只有一种来源：**被推/拉**（挨打）。
「我冲上去」这件事从来没发生过——难怪看不到。

## 2. 数据规模

| 侧 | 带 `move` 的技能 |
|---|---|
| 英雄 | 12 个，覆盖 8 个职业（十字军/强盗/小丑/盗墓贼/恶女/憎恶/老兵/古董商） |
| 怪物 | **101 个**（第一版列出来时我也没想到：土匪「点燃引信」要退 3 格，猪人钩子每用一次退一格） |

## 3. 方向怎么定的（没有文档，只能推）

`move` 是 `[a, b]` 两个数，总有一边是 0。用三个**行为已知**的技能反推：

| 技能 | 值 | 原版行为 | 结论 |
|---|---|---|---|
| 零距离开枪 `point_blank_shot` | `[1,0]` | 强盗**后退** 1 | 第 0 位 = 后退上限 |
| 圣枪突进 `holy_lance` | `[0,1]` | 十字军**前进** 1 | 第 1 位 = 前进上限 |
| 点燃引信 `light_fuse` | `[3,0]` | 土匪**退到队尾** | 同上，退 3 |

两个独立的确证（后退 1 / 退到队尾）足够定序，不是猜一个能对上就算。

## 4. 实现位置：**目标循环之外**

`_resolve_action` 是**逐目标**调用的（AOE 技能会循环 N 次）。位移放在那里，
一个打全体的技能会把施法者挪 N 次——而且不报错，只是人莫名其妙跑到最前排。

所以插入点在 `_apply_choice` 的循环之后：

```gdscript
	for t in targets:
		if t.dead:
			continue
		_resolve_action(actor, action, t)
	_apply_caster_move(actor, action)     # ← 一次，不是 N 次
```

### 三条边界

| 情况 | 处理 | 为什么 |
|---|---|---|
| 已经在最前/最后 | `move_unit` 返回空 → 不发事件 | 否则日志会写一句「前进到 1 号位」，而人没动 |
| 被反击打死 | 先判 `is_alive()` | 尸体不排队 |
| 没打中 | **照样挪** | 原版位移是动作的一部分，不是命中奖励。`_resolve_action` 里四条分支各自 return，插在任一分支里都会变成「只在中了才挪」 |

## 5. 界面：三处配套

### a) 日志要区分「我自己冲」和「我被推」

`move` 事件原来只有两种读法：主动调整（`skill == "move"`）和被打乱（`shuffle` / push / pull）。
自发位移落进 `else` 会被写成「十字军 被推到 2 号位」——**看起来像挨了打**。

加一个 `self` 标记，并把这一支排在 push/pull 前面：

```
　十字军 前进到 3 号位        （绿）
　强盗 后退到 3 号位
```

### b) 出招补间：近战冲锋 / 远程后坐

原来一律 26px 前冲。两个问题：

- 26px 在 1080 宽下一格是 143px，只有 1/5 格，配 0.42 秒正弦曲线**基本看不出来**
- 开枪也在往前撞

改成按**命中音的种类**反推（M52 已有「动作名 → 武器」这张表，不必再判断一次技能类型）：

| 种类 | 位移 | 缩放 |
|---|---|---|
| 近战（sword/knife/spear/shield/whip/general） | 前冲 **42px** | +7% |
| 远程（arrow/gun/gas/liquid/magic_dark/staff） | 后坐 **9px** | +2.5% |

顺带修了一个更隐蔽的：`_pose_for_action` 原来**没有姿势帧就直接 return**，
于是怪物（素材只有英雄）从来不会有 `_pose` 记录，**出手时完全不动**。
现在姿势帧为空也记 pose（帧名留空，绘制端会退回 `combat`），怪物也有冲的动作了。

### c) 技能按钮右上角的 `进N` / `退N`

位移是**决策相关**的信息——同一个伤害的两种打法，一种会把你送到前排。

塞进副标题不行：1080 下副标题只剩 144 宽，已经是「修正 -80% · 命中 +95% · 敌 …」了。
所以单独画一个角标，同时把技能名可用宽度减 26px（不减的话会连读成「圣枪突进1」）。

## 6. 验证

12 项新断言（总 **1322 项全绿**，自检 PASS）：

```
── 位移：技能自带的挪位 ──
  十字军装载了 holy_lance / move 是 [0,1]
  圣枪突进后 4 号位 -> 3 号位（两个目标也只挪一格）
  位移事件带 self 标记 / 记着是哪个技能挪的
  零距离开枪后 2 号位 -> 3 号位（后退一格）
  已在最前排突进不动 / 挪不动时不发 move 事件
  闪避顶满后这一下确实没打中（产生 miss 事件）
  没打中也照样突进（4 号位 -> 3 号位）
```

> 造「必空」这一条踩了个坑：压 `atk` 到负数**不行**——`_resolve_action` 里
> `atk <= 0` 会被判成功能技，连命中判定都不走，压根不产生 `miss` 事件。
> 正确做法是把目标闪避顶到上限 0.95。

### 真打出来的证据（不是测试桩）

四个区域各跑一趟自动远征（`--dev` 打印自发位移），只有 crypts/weald 那两趟没触发：

```
--- warrens
[move] 猪人砍杀者 后退 2 -> 3 (hook_where_it_hurts)
[move] 猪人砍杀者 后退 3 -> 4 (hook_where_it_hurts)
[move] 邪教打手 前进 2 -> 1 (brawler_claw)
--- cove
[move] 邪教打手 前进 3 -> 2 (brawler_claw_weak)
[move] 强盗 后退 1 -> 2 (point_blank_shot)      ← 英雄侧
```

`crypts`/`weald` 那两趟没出现，是因为**遇上的怪正好都不会位移**（骷髅、狗、乌鸦），
不是功能没跑。判据要看「技能表里有没有 move」，不是「这一趟有没有」。

### 可复现的数值证据（`.tmp/proof_move.gd`）：

```
圣枪突进前：十字军在第 4 位
圣枪突进后：十字军在第 3 位
零距离开枪前：强盗在第 1 位
零距离开枪后：强盗在第 2 位
  第1轮 hook_where_it_hurts 自发位移 1 → 2（后退）
  第2轮 hook_where_it_hurts 自发位移 2 → 3（后退）
```

**顺带修了一条既有断言**：`test_move.gd` 里「20 场里发生了 N 次被技能推动」统计的是
`move` 事件里 `skill != "move"` 的那些。自发位移也满足这个条件，会把断言喂饱，
于是测不出「怪物到底会不会推人」。现在排除 `self`。

## 7. 已知限制

1. **AI 不估位移。** `_score` 没改——它仍然只看伤害/压力/效果。所以怪物可能为了
   0.5 伤害把自己挪到不利位置，玩家也看不到「这一招会把我送到前排」的提示之外的信息。
   这是 M11 就存在的问题（当时只补了「推拉」的估值），不是这期引入的。
2. **角标没有截到图。** 十字军的先攻是 1（永远最后行动），而技能面板只显示
   **当前等待输入的那一个英雄**，所以拿不到他的面板。`_move_badge` 本身用直接调用验证过
   （`[0,1] → 进1`、`[1,0] → 退1`、`[0,0] → 空`），布局也由几何保证
   （名字宽度减 26px、角标右对齐画在那 26px 里）。要亲眼看：让强盗或十字军先动。
3. **位移不判抗性。** 技能自带的位移是「动作的一部分」，原版也不吃 move 抗性
   （抗性只作用于被打乱/推拉）。这一条是刻意区分，不是漏。
