# 绿皮兽人狂战士动作包

所有图集均为透明 RGBA，朝右，24 fps。行走原地循环，位移由游戏控制。非循环动作在图集最后一帧结束，倒地动作停在倒地姿势。

| 动作 | 帧数 | 关键事件 |
| --- | ---: | --- |
| 探索待机 | 44 | 放松站姿与呼吸循环 |
| 探索行走 | 24 | 两次脚步事件在 0 和 12 帧 |
| 战斗待机 | 34 | 负重站姿与提斧呼吸 |
| 架斧防御 | 22 | 架斧、保持、回到站姿 |
| 受击后仰 | 15 | 第 2 帧受击 |
| 阵亡倒地 | 33 | 第 11 帧落地 |
| 沾毒待机 | 60 | 保留原样件的喘息与毒雾 |
| 交叉破甲 | 25 | 第 9 帧结算伤害，两道斧光交叠 |
| 双斧坠劈 | 34 | 第 15 帧结算伤害，落斧后尘土扩散 |

表中帧索引从 0 开始。查看器的帧编号从 1 开始。交叉破甲的伤害事件为 0.375 秒，双斧坠劈为 0.625 秒。在游戏里应由技能逻辑确定实际伤害数值和目标。

`actions-index.json` 是资源入口。每条记录指向动作的图集参数、透明预览和可编辑关键姿势数据。新的动作图集为 460 × 392 单帧，静止脚底锚点为 (210, 333)。原沾毒待机保持此前的尺寸和锚点。图集 JSON 含该动作的实际帧矩形与锚点。`fx_texture` 如存在，可与本体共用同一矩形和锚点叠加。WebP 预览已合成相应特效。

`parts/` 包含原始 7 个部件和行走新增的两条腿、骨盆腰布 3 个部件。`poses/` 保存交叉破甲出斧、双斧坠劈落斧和阵亡倒地三张透明重绘姿势。动作图集 JSON 的 `joint_positions` 在使用专用整张姿势时记作 `null`。原沾毒待机的骨架源数据保持在 `poisoned-idle-rig.json`。

在项目样件目录双击 `viewer.html` 可切换九条动作，逐帧验收骨架、伤害事件和独立特效。已验证离线图集与播放时序。当前 Godot 项目尚无这些新动作的接线，也没有生成原生 Spine 工程。

## 美术提示

用内置 ImageGen 按原立绘重绘三个全身关键姿势。保持绿皮、面部伤疤、耳环、两把短柄斧、交叉胸带和破红腰布。交叉破甲使用向右突进、高低双斧交叠的剪影。双斧坠劈使用压低重心、两把斧头同时砸在右前方的落点。阵亡使用身体伏倒、头朝右、斧头低垂的静止剪影。三张都保留透明背景，斧光与落地尘土由渲染器绘制。
