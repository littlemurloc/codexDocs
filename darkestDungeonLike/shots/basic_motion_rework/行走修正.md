# 行走动作修正

### 原因

上一版用原画中的双脚位置作为各自的步态中心。兽人两只脚踝整圈的 X 差值为 −77.3 至 −29.5 px，暗精灵为 14.7 至 69.0 px。前后关系全程未交换。兽人的远侧膝根据近乎伸直的绑定姿势推断弯曲方向，符号恰好反了。步态进入摆动和重新承重时，脚的水平速度还会从匀速跳到零或从零跳到匀速。

### 修正

将前后脚的投影轨迹收进同一个步幅，设置正向膝关节，按实际靴底轮廓处理鞋跟到鞋尖的滚动。脚从蹬离到摆动再接地时，水平速度连续。清掉透明拆件中遗留在错误图层的碎边。兽人用稍长的双脚承重区间和更低的抬脚幅度，暗精灵的步频更快。

新版兽人为 28 帧，暗精灵为 24 帧，均为 24 fps。新版脚踝的 X 差值在两位角色的循环中均跨过零。查看器的“看旧版”对行走会回到本次修正前的上一版。对照 GIF 按相同步态相位展示，独立动画保留各自的实际步频。

图集 JSON 中的 `travel_pixels_per_cycle` 为每循环建议位移，`ground_y_by_side` 记录三分之四视角的近远脚投影地面。如果运行时以恒速前进，用建议位移除以周期同步画面，可让承重脚相对场景保持稳定。本次验收覆盖离线动画、脚底与关节数据和查看器切换。
