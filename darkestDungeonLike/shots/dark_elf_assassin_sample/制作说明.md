# 暗精灵女刺客

面向右侧的双匕首角色。灰紫皮肤、银白长辫、旧皮甲与暗红腰布。所有动作按 24 fps 输出，单帧 460 × 392，脚底锚点 (210, 333)，和兽人的新动作资源使用同一规格。

| 动作 | 帧数 | 说明 |
| --- | ---: | --- |
| 探索待机 | 42 | 落肩呼吸、辫梢轻摆 |
| 潜行步 | 24 | 原地循环，第 0 和 12 帧为脚步事件 |
| 战斗待机 | 36 | 屈膝持双刃，肩与手腕运动 |
| 双刃招架 | 19 | 提刀招架后回到站姿 |
| 受击后撤 | 14 | 第 2 帧受击事件 |
| 阵亡倒地 | 29 | 第 10 帧落地，结束时保持倒地姿势 |
| 暮影突刺 | 23 | 第 7 帧标记命中，0.292 秒 |
| 回月双切 | 28 | 第 10 和 14 帧标记两次命中，0.417 和 0.583 秒 |

表中帧索引从 0 开始。查看器以 1 开始显示帧编号。伤害数值由游戏技能系统决定。

- `actions-index.json` 指向各动作的图集描述、动作源数据和透明 WebP。
- 图集的 `fx_texture` 是独立特效，按本体格子和锚点原位叠加。WebP 已合成相应特效。
- `rig-binding.json` 保存十个部件的父级、来源坐标、局部转轴和绘制顺序。按帧记录的关节点在专用重绘姿势上记作 `null`。
- `parts/` 是透明拆件，`poses/` 保存补绘来源与两招、倒地三张专用姿势。
- `source/split_parts.py` 和 `source/render_actions.py` 可用 Pillow 与 NumPy 重新生成。接续动作用这两份源文件修改，原始提示词见 `source/art-prompts.json`。
- 项目内双击 `viewer.html` 可离线观看，两页共享兽人样件目录中的查看器脚本和样式。动作包提供离线资源与生成源，尚未做 Godot 战斗接线或原生 Spine 导入。

立绘、隐藏区域补绘和三个专用姿势由内置 ImageGen 生成。透明拆件、部件绑定、时间轴和独立特效在此样件内制作。
