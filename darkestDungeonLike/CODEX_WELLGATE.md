# 卷一 · 城

## 1.1 四个环

井门城建在坑口上，一圈一圈往外长。

- **内环（坑口台到验收所）**：地价最贵，因为离井最近。货一上来就进这里。
- **中环（铁匠街、药铺、盐仓、酒馆、当铺）**：城的八成人口在这儿，白天最吵。
- **外环（教堂、学院、总督府、住家）**：石头房子，路是平的，晚上有灯。
- **墙外（棚区）**：不算城。没门牌，没税，也没人管你死在哪。

**一条对美术有用的规矩**：城里没有一条路是水平的。坑口每年下沉两寸，所有主路都是缓坡，房子每年垫一次地基。所以墙根都有一圈新旧不一的石砌补丁。

## 1.3 逐处

### 一 · 坑口台

一个大得离谱的木台，架在坑口上，四角各有一台绞盘。台面中间是个方洞，洞下面就是黑的。

吊手四人一组，喊着号子往下放绳。绳上挂的是升降篮——铁框，能装六个人或者两吨货。

**玩家能做的**：编队、下井、看别人上来。上来的人会被围住问"下面怎么样"，这是城里最主要的信息交换。

**闲话**："别看下面。看久了会觉得下面也在看你。"——吊手说的，说完自己笑。

### 二 · 公会大厅

长条石屋，正中是委托板，后墙是牌子墙。

牌子墙有一面半墙高，挂满了木牌。每块牌子上刻着名字和队号。挂不下就叠着挂，叠到后来分不清哪块是谁的。

**玩家能做的**：接委托、卖战利品、提升评级、查阵亡名单。评级从"新人"到"老手"到"下潜者"，决定能接什么委托。

**注**：牌子墙最下面那几排，磨损得特别厉害。执事说是因为潮。

### 三 · 验收所

一个小石屋，开在坑口台边上。所有从井下带上来的东西都要过这里。

税吏会翻你的包，问三件事：哪来的、几层、有没有见过人。

**玩家能做的**：交税（货物价值的十分之一）、买下井许可（按层计价）、被盘问（如果带上来不该带的东西）。

**注**：验收所的墙上贴着一张告示，写着"第七层以下不在合约范围内"。告示很旧，边角被撕过又粘回去。

### 四 · 铁匠街

一条窄巷，八个炉子，白天热得站不住人。

布洛克的铺子在巷子最里头，门口挂着一把打歪的剑——那是他爷爷的爷爷打的，据说用的是第七层的铁。

**玩家能做的**：买普通武器、修装备、用黑铁打造（黑铁要自己带）。布洛克打黑铁有个规矩：先看铁，再看人，人不顺眼给多少钱都不打。

**闲话**："黑铁不听话。你越想它硬，它越软。"——布洛克

### 五 · 药铺

门口挂着干草药，屋里有股苦味。

药师姓吴，五十多岁，手很稳。他主要治三种伤：外伤、毒、还有"井气"。

**玩家能做的**：解毒、治伤、买药。井气治不好，只能压——喝一碗苦药，能压三天。

**注**：吴药师的本子上记着每个病人的"下潜天数"。他从来不问，只记。有人问他记这个干什么，他说"以后有用"。

### 六 · 盐仓

三个大仓，堆的都是盐。粗盐、细盐、腌过的盐。

盐有两个用处：腌食材防腐，撒在地上驱虫。下潜队出发前都要来领一包。

**玩家能做的**：买盐、寄存货物（按天收费）、把战利品腌了再卖（能多卖三成）。

### 七 · 三盏灯酒馆

城里唯一一家通宵开的酒馆。招牌上画着三盏灯，第三盏是灭的。

**玩家能做的**：招人（雇 NPC 队友）、打听消息（花钱买传闻）、喝酒（回士气，掉钱）。

**闲话**："第三盏灯为什么灭着？"——"等下面的人回来点。"

### 八 · 当铺

柜台很高，老板坐得比你高一头。

**玩家能做的**：抵押装备换钱、赎当、买二手装备（便宜，但可能有暗伤）。

**注**：当铺后屋堆着很多没人赎的东西。老板说那些都是死人的，等满了三年就卖掉。

### 九 · 守望教堂

石头教堂，没有钟，只有一口井——教堂正中间也有一口小井，深不见底，用铁栅盖着。

教会信"守住门"。他们办葬礼、安魂、给下潜队祝福。

**玩家能做的**：安魂（消除一次精神类负面）、办葬礼（如果队友死了）、买圣水（对不死生物有效）。

**注**：教堂地下的井和坑口是同一口井。教士说这是"为了随时看着它"。

### 十 · 勘探学院

一栋三层楼，墙上挂满了地图。有些地图画到一半就断了，断口处写着"到此为止"。

柯温在这儿做研究。他的桌子永远堆着三样东西：放大镜、冷掉的茶、和一张画了七层的剖面图。

**玩家能做的**：卖情报（新层的路线、新怪物的习性）、鉴宝（认不出来的东西可以拿来问）、翻译古文字（贵，且慢）。

### 十一 · 总督府

全城最气派的建筑，也是唯一用直墙的。

总督姓维尔，五十岁，来这里七年，一次井都没下过。他关心三件事：税、兵、别让卡尔迪人进来。

**玩家能做的**：领官府赏金、接官府委托（护送、清剿、封路）、打官司（很难赢）。

### 十二 · 墙外棚区

帐篷、板房、泥路。没有门牌，没有税，也没人管你死在哪。

黑市在这儿，卖的是来路不明的东西：别人的装备、别人的牌子、别人的牙。

**玩家能做的**：雇便宜人手（便宜，但会跑）、买黑市货、找小满（她认识所有在棚区混的孩子）。

## 1.4 六方势力的委托

| 势力 | 委托模板 | 报酬 | 风险 |
|---|---|---|---|
| **公会** | 清理某层的巢穴 / 护送学者下三层 / 找回失踪队伍的牌子 | 金币 + 评级 | 中 |
| **总督府** | 护送税银 / 清剿棚区闹事者 / 封住某条私捞通道 | 金币多，但有政治后果 | 中高 |
| **井务署** | 送补给到第七层关卡 / 押送违规下潜者 / 修补七号门 | 通行许可 | 高（可能和赫兰对上） |
| **黑铁商会** | 押运黑铁 / 抢占新矿点 / 打压私贩 | 钱最多 | 高（会得罪人） |
| **勘探学院** | 采集样本 / 测绘某层 / 带回一块"有字的墙皮" | 钱少，但给情报 | 中 |
| **守望教会** | 安葬井下的死者 / 送圣水到第六层 / 调查"闹鬼"的营地 | 祝福 + 圣水 | 低中 |

**设计原则**：同一件事可以从两方接。比如"清理第四层的构造体"，公会给你钱，学院给你情报，商会想让你顺路带一块黑铁回来。**玩家选谁，决定他和谁的关系变好、和谁变差。**

# 卷二 · 人

## 2.1 五个种族

| 种族 | 在城里的位置 | 对井的态度 | 一句话 |
|---|---|---|---|
| **人类** | 主体。什么活都干 | 井是饭碗 | "总得有人下去。" |
| **矮人** | 铁匠、石匠、矿工 | 井是祖坟。他们的祖先在第四层 | "我们挖的，我们认。" |
| **精灵** | 学院、教会、少数商人 | 井是伤口。他们主张封 | "有些洞不该挖。" |
| **半身人** | 厨子、商贩、跑腿 | 井是市场 | "下面的东西，上面的人爱吃。" |
| **龙裔** | 稀少。多在商会 | 井是禁忌。他们不和井打交道 | "我们不谈那个。" |

**注**：龙裔对井的回避是有原因的，但他们不说。玩家如果追问，龙裔 NPC 会转移话题。这是唯一一个"玩家可能提前撞上真相"的入口——但因为龙裔本来话就少，多数玩家会当成种族设定。

## 2.2 六个战斗职业

| 职业 | 定位 | 一句话 |
|---|---|---|
| **战士** | 前排、扛伤 | "站我后面。" |
| **法师** | 远程、控制、照明 | "灯是我的，别碰。" |
| **盗贼** | 爆发、开锁、探路 | "我先下去看看。" |
| **牧师** | 治疗、驱散、安魂 | "别怕，它还认得你。" |
| **游侠** | 远程、陷阱、追踪 | "三个小时前有人从这儿过去。" |
| **厨子** | 补给、增益、应急 | "先吃，吃完再打。" |

厨子是**战斗职业之一**，但它的作用是让队伍撑得更久，不是让伤害更高。一支只有厨子的队伍打不动任何东西。

## 2.3 主要人物

### 赫兰·维斯（封井队队长）

四十岁，女的，短发，左手小指缺一截。穿井务署的黑甲，甲上有旧修补的痕迹。

她不多话，但每句都算数。手下的兵怕她，也服她。

**她要什么**：守住七号门。不是因为她信教会那套，是因为她爷爷是封井那批人里的一个，临死前说过一句"下面有东西在数人"。

**她的矛盾**：她知道封不住。她只是想让封的时间再长一点。

**玩家能得到**：通行许可、第七层的补给、以及一句"你们迟早要下去，我只是让你们晚点死"。

### 老陶（路线贩子）

瞎子。六十岁往上，脸晒得黑，眼睛是灰白的。拿一根竹竿，走路比很多明眼人稳。

他卖路线图，一张五个金币，不还价。他的图画得比公会的好，因为他"闻得出来哪条道通了"。

**他不知道的事**：他闻的不是路。他闻的是井。二十年前他下过五层，上来就瞎了，从那天起他就能"闻"到井的变化。他一直以为这是瞎子的本事。

**玩家能得到**：路线图、井的"状态"（哪层在变、哪层安静）、以及一句"下面最近在动"。

### 米拉（黑铁商会少主）

二十二岁，女的，穿得比总督还体面。她爹中风了，商会现在她说了算。

她做生意很狠，但守规矩：说好的价不会变。

**她要什么**：垄断黑铁，把她爹留下的烂账填平。

**她的矛盾**：她其实知道黑铁是什么，但她不敢想。她只在喝多了的时候说过一句"我爹说那铁是长出来的"。

**玩家能得到**：钱、货、以及卡关时的一条"商会的路子"。

### 柯温（勘探学院学者）

三十岁，男的，眼镜厚，手指上有墨。他说话快，一激动就结巴。

他来井门城六年，画了六年的剖面图。他的图越画越厚，因为他发现层数一直在增加。

**他要什么**：弄清这坑是什么。

**他的恐惧**：他其实已经猜到了。他不敢往下写，所以他的论文永远停在"结论待定"。

**玩家能得到**：鉴定、翻译、古文字线索、以及真相线的主要推进。

### 布洛克（矮人铁匠）

一百四十岁，矮人里算中年。手臂粗，胡子编成三股，用铁环扣着。

他打铁的时候不说话。打完会说一句，通常是骂人的。

**他要什么**：打出一把"听话的黑铁剑"。他爷爷没打成，他爹没打成，他想打成。

**玩家能得到**：装备、修理、黑铁打造、以及矮人线的入口（他祖先在第四层）。

### 小满（坑口捡漏的孩子）

十二岁，女的，瘦，跑得快。她娘在盐仓做工，她爹死在第三层。

她靠捡下潜队掉的东西活着。她认识棚区所有的孩子，也认识所有的黑市贩子。

**她要什么**：攒钱，买一盏自己的灯。

**她的作用**：她是玩家的情感锚点。第三章她会偷偷跟下三层，然后失踪——玩家要在第四层找到她。

### 补锅的（第五层的瞎老头）

详见 WORLD §6.4。这里只补三条玩家可见的细节：

- 他的锅底有一层很厚的黑垢，刮下来能当灯油用。他说这是"补了一千年锅攒的"。
- 他数人数的方式是摸牌子。他会摸玩家的牌子，然后说"这块新"。
- 他从来不问"下面有什么"。他只问"上面还好吗"。

## 3.2 逐层

### 第一层 · 塌陷旧城

**遭遇表**

| 怪物 | 数量 | 威胁 | 掉落 |
|---|---|---|---|
| 鼠群 | 3–5 | 低 | 鼠尾（钓饵）、生肉 |
| 食腐甲虫 | 2–4 | 低 | 甲壳（做甲片）、酸腺 |
| 塌陷守卫 | 1–2 | 中 | 旧铁、齿轮、构造核心（稀有） |
| 落石 | — | 环境 | 无 |

**素材**：旧铁、鼠肉、甲壳、酸腺、霉面包（能吃，掉士气）

**事件**：遇到一支刚上来的队伍，他们会告诉你"别走中间那条街，会塌"。如果玩家不听，中间那条街真的会塌（一次性事件）。

**注**：守卫的甲上有纹章。和总督府门口的一样。

### 第二层 · 水道与菌林

**遭遇表**

| 怪物 | 数量 | 威胁 | 掉落 |
|---|---|---|---|
| 菌人 | 4–8 | 低（不主动） | 菌盖、孢子、菌肉 |
| 盲鱼 | 3–6 | 低 | 鱼肉、鱼油 |
| 水蛭 | 5–10 | 低 | 吸血囊（药用） |
| 沼蟒 | 1 | 中 | 蟒皮、蟒胆 |

**素材**：菌肉（主食）、孢子（致幻）、鱼油（灯油替代）、蟒胆（解毒）

**事件**：静水潭。扔石头下去没有回声。玩家可以潜水，水底有一扇锁着的铁门（打不开，钥匙在第七层）。

**注**：菌盖上的纹路能拼字。拼出来是"别往下"。学院给的鉴定结果是"孢子生长的自然纹路"。

**事件**：无名家。屋里有桌椅、锅、床，两副碗筷。锅是热的。第二次来，碗筷变三副。

**注**：墓碑全部朝下埋，碑文朝内。

## 4.4 料理

**四要素**：火、盐、香料、时机。

**三类用途**：

| 用途 | 做法 | 效果 | 代价 |
|---|---|---|---|
| 补给 | 腌、熏、煮糊 | 回饱食，多撑几天 | 难吃，掉士气 |
| 战前 | 炖、烤、配香料 | 抗性/属性增益，持续一场 | 出井失效 |
| 战中 | 生吃、嚼 | 立刻回血/解一个状态 | 掉理智 |

**示例菜谱（八道）**

| 菜 | 素材 | 效果 | 代价 |
|---|---|---|---|
| **菌汤** | 菌肉 + 盐 | 回血，抗毒 | 无 |
| **盐渍盲鱼** | 盲鱼 + 大量盐 | 饱食 + 夜视 | 口渴（要多喝水） |
| **甲壳炖** | 甲壳 + 鼠肉 | 加护甲，持续一场 | 行动变慢 |
| **尸油炒饭** | 尸油 + 米 | 战中回血 | **掉理智** |
| **龙血酒** | 龙血 + 香料 | 加力量，加暴击 | 中毒风险，处理不好会死 |
| **铁壳烧** | 构造核心 + 精铁屑 | 抗钝击 | 极难吃 |
| **黑铁茶** | 黑铁屑 + 水 | 抗腐蚀 | 喝完牙齿发黑 |
| **一锅乱炖** | 任意三样 | 随机效果 | 随机代价 |

**设计原则**：料理的效果**不能替代装备和等级**。它只解决"能不能撑到下一层"。

# 附录 A · 与 data/ 的字段映射

| 图鉴内容 | 现有落点 | 改法 |
|---|---|---|
| 七层 | `dungeons.json` 的 `meta` / `encounters` / `props` 键 | 现有 6 个区域键（cove/crypts/weald/warrens/darkestdungeon/town）→ 换成 `floor_1`…`floor_7`；`meta` 加 `depth`、`recommend_level` |
| 每层遭遇 | `encounters[region][level]` | 结构不变，直接换怪物 id |
| 怪物 | `monsters.json`（现 254 条） | 保留字段（family/stats/skills/loot），换 id 与名字；新增 `floor` 字段 |
| 素材 | `loot.json` 的 `loot_tables` | 新增素材类 item，挂在各层的掉落表 |
| 料理 | **无**（需新建 `cook.json`） | 字段：`id / materials / fire / salt / spice / timing / effect / cost / tier` |
| 装备 | `inventory.json`（52 条） | 加 `material` 字段（铁/精铁/黑铁/遗物） |
| 城镇设施 | `campaign.json` 的 `buildings` | 现有"建筑"换成"十二个去处"，功能对齐 |
| 委托 | `quests.json` | 加 `faction` 字段（六个势力），同一目标可被多方发布 |
| 势力关系 | **无**（需新建 `factions.json`） | 字段：`id / rep / effects` |
| 井气 | `expedition.json` | 新增 `dive_days` 计数器与阈值 |
| 补锅的 | 无 | 第五层固定 NPC，需 `npc.json` 与对话表 |
| 三结局 | 无 | 终局分支，需要 flag：`seal / guard / tell` |

**最省事的三处**：遭遇表换 id、装备加 `material`、委托加 `faction`。这三样不需要新系统。
**最贵的三处**：`cook.json`（全新）、`factions.json`（全新）、三结局（全新分支）。

# 附录 C · 还没定的

- **十二个去处是否都要做成可交互**。建议先做六个（公会、铁匠、药铺、酒馆、学院、总督府），其余用文本。
- **每层遭遇表的具体数量**要按现有 bench 的战斗时长反推，不能拍脑袋。
- **料理的"掉理智"**是数值还是叙事，影响整个烹饪系统的定位。
- **无面者**是否可战斗。现在的设定是"不攻击，只跟随"，如果玩家能打，会破坏压迫感。
- **七层的推荐等级 1–9** 是否和现有等级上限（5）冲突。如果要九级，技能表要重做。
