依据：[Y3 编辑器 ECA 实装规范](../docs/y3-eca-implementation-standards.md)。用于每次技能、Buff 或卡牌实装与重构，与玩法验收分开记录。以下是空白模板，不代表当前工程已经验收。

任务／地图／版本：待填写。适用资源与调用链：待填写。检查人及时间：待填写。

每项填写“通过／失败／待验证／不适用”，并给出文件、页面、测试或日志证据；不适用项注明原因。未执行的检查不得记为通过。

## 范围与实现

- [ ] 已确认设计口径、对象、数值及本次边界；列明公共触发器、函数库、物编、配表、事件声明、卡池和表现的变更状态。
- [ ] 已读取本图原生实例，分别核对获得、等级变化、失去等适用事件的参数。
- [ ] 持有记录、卡牌 KV、公共规则和缓存各有明确来源，无重复维护的名单或数值。
- [ ] 公共逻辑按职责组织，函数和变量命名可读，特殊条件及顺序有说明。
- [ ] 已确认写表和引擎事件先后；首次尚无记录、合成及失去时序有对应处理。
- [ ] 延迟回调、伤害后处理、Buff 删除及失效来源有必要的对象检查。
- [ ] 重复应用、撤销、生命处理、收益互斥和条件交集符合本次口径。
- [ ] 监听、定时器、缓存和持续表现有清理；初始化与周期检查没有无谓重复创建。

## 静态与离线检查

- [ ] 类型、作用域、ID、关联、目录登记和引用已检查；批量修改已全量扫描所有适用入口。
- [ ] 测试按事件实际能力约束参数；已覆盖本次修复的失败案例。
- [ ] 已验证相关数值、重复刷新、失去重获、无效记录、玩家隔离及涉及的时序；不适用项有说明。
- [ ] 离线通过的范围和不能模拟的引擎行为分别记录。

## 写回与编辑器检查

- [ ] 有变更清单与备份；发布前核对当前版本，无并发改动被覆盖。
- [ ] 已写回并重载／保存回读，检查编辑器没有丢参数、把变量变常量或清空引用。
- [ ] 已按事件与参数写法检查页面红字、无效调用与错误资源引用；注明实际打开的资源范围。
- [ ] 写明全量扫描、页面抽查和未检查范围；没有把元数据或导出一致当成完整页面验收。
- [ ] 生成器／模板与最终修复一致，历史候选和迁移器的适用范围明确。

## 实战与报错归因

- [ ] 已记录获取、升级、合成、失去／重获、换波、补兵及战斗中实际执行的适用场景。
- [ ] 检查重复应用、贡献撤销、来源销毁和多玩家隔离；填写未覆盖的边界。
- [ ] 已核对最新日志；错误按资源、节点及调用链定位，必要时与改动前日志比对。
- [ ] 区分本模块直接错误、共享链旧问题和未经证明的间接影响，未越界修复暂缓模块。

## 表现与交付结论

- [ ] 机制、数值、粒子／光环、音效／动画、图标／UI 和卡池接入分别注明状态。

- [ ] 说明改数值、新增同类卡、新属性和新机制的维护入口。
- [ ] 最终结论分列静态、离线、编辑器及实战证据，保留失败项、待验证项及回退位置。
