# Y3 ECA 交付验收清单

任务／地图／版本：待填写。适用资源与调用链：待填写。检查人及时间：待填写。

每项填写“通过／失败／待验证／不适用”，并给出文件、页面、测试或日志证据；不适用项注明原因。未执行的检查不得记为通过。

## 范围与实现

- [ ] 已确认设计口径、对象、数值及本次边界；列明公共触发器、函数库、物编、配表、事件声明、卡池和表现的变更状态。
- [ ] 已读取本图原生实例，分别核对获得、等级变化、失去等适用事件的参数。
- [ ] 持有记录、卡牌 KV、公共规则和缓存各有明确来源，无重复维护的名单或数值。
- [ ] 可调整门槛集中配置，所有资格调用读取同一口径，无遗留写死参数；待替换旧资源的改名／效果／报价／收集资格范围分别登记。
- [ ] 复用旧函数／属性前已核对收益来源、接受单位、判定对象、结算时机、叠加规则和公式入口。
- [ ] 公共逻辑按职责组织，函数和变量命名可读，特殊条件及顺序有说明。
- [ ] 高频读取复用限定于已确认稳定的本次调用，局部变量原生类型正确；下一次调用重新赋值，未把可变化属性／目标跨攻击缓存或越过有效性前置条件。
- [ ] 显示合并已区分玩法与表现：伤害、层数、属性及满层联动保持原时序；允许合并的数字／格子有明确最新状态与玩家接收范围，未机械合并逐事件飘字或粒子。
- [ ] 显示缓存按实际来源实例隔离，同一来源最多一个待刷新；覆盖首次绘制、重建、实例替换、颜色／规则与拥有者变化，未完成显示不误记成功，重建后主动首次刷新。
- [ ] 已确认写表和引擎事件先后；首次尚无记录、合成及失去时序有对应处理。
- [ ] 持卡快照已检查有效性、归属、分类及去重；报价屏蔽、组件移除、结果持有和收益撤销分开检查。
- [ ] 结果牌持有、自然合成完成、组件折叠和报价解锁分别判断；提前赠到结果后，组件集齐仍正确收尾，不重复发结果或抽奖，赠送不提前冒充路线完成。
- [ ] 路线已解锁阶段、自然完成、待授予结局和本局已领取分开保存；明确锁定时机，控制器重建不重置玩家进度；允许当前组收尾时未把正常结算一起禁用。
- [ ] 特殊终局比较的是已解锁还是已完成已明确；资格成立时固定目标与来源，失败重试不因其他路线随后变化而改结局，未成功不记已领取。
- [ ] 合成资格、普通报价与自动奖励分别筛选；后继关系读原配置，只开放对应普通组件，终局资源不能被组名批量开放；无合格下一组时不推进阶段。
- [ ] 已为持续属性、首次奖励、每波效果、击杀收益及永久成长明确适用的状态范围、去重标识、上限与失效规则。
- [ ] 每波效果按真实波次去重，途中获得是否追补有口径；终极资格完整，授予前有重入保护，重复回调不重复授予。
- [ ] 本局限领状态按玩家保存，与可销毁控制器及当前持有分开；实际授予成功后记账，重复请求、失去重获、控制器重建不会突破上限。
- [ ] 选卡、自然合成、随机赠送和终极授予来源明确；嵌套授予有来源隔离及恢复，异步按独立上下文处理；候选池为空时不重复发牌。
- [ ] 战斗计时只在指定阶段推进，调度间隔与累计步长同源；备战暂停、换波及失卡重获的进度规则明确。
- [ ] 延迟回调、伤害后处理、Buff 删除及失效来源有必要的对象检查。
- [ ] 重复应用、撤销、生命处理、收益互斥和条件交集符合本次口径。
- [ ] 各终局独有属性、单卡被动、共同终极及历史套牌收益分别核对，替换关系未重复发卡或叠加两套终局收益；旧名／设计名／路线映射与资源复用口径已记录。
- [ ] 监听、定时器、缓存和持续表现有清理；初始化与周期检查没有无谓重复创建。

## 静态与离线检查

- [ ] 类型、作用域、ID、关联、目录登记和引用已检查；批量修改已全量扫描所有适用入口。
- [ ] 同图独立函数FID和根级触发器ID分别全量检查；复制／移动区分身份保留与重新分配，未把跨地图或内嵌元素ID的作用域混为全项目唯一。
- [ ] 独立ECA与物编trigger_dict封装使用对应结构检查；工具不支持、缺少检查范围和实际工程错误分开记录，未以封装缺根字段误判损坏或直接记为通过。
- [ ] 追踪开关按资源、节点、动作及完整参数登记并可逆；动态参数无玩法副作用／随机序列变化，未登记或参数改变时先审查，维护中的追加工具遵守同一模式。
- [ ] 原生 API 允许的操作数类型已核实，资源引用与运行时实例分开检查；没有把 MAP 传给 `TYPE_IS_EXIST` 等未支持的类型组合。
- [ ] 可选参数的位置、类型与启用状态在生成、模型计算和编辑器回读中一致；启用参数未遗漏，禁用参数未执行。
- [ ] 固定表资源和运行时表表达式编码已区分；“无效的表”已按声明、作用域、登记和参数编码排查。
- [ ] 动态字符串KV键直接传表达式，未被公共读写辅助函数包装成字符串常量；模型拒绝常量内嵌表达式。
- [ ] 设置返回值与退出执行分开核对；布尔函数有明确的结果初始化、分支更新和最终输出，后续动作不会错误覆盖结果。
- [ ] 测试按事件实际能力约束参数；已覆盖本次修复的失败案例。
- [ ] 返工检查能重现旧缺陷并检验修正版；解释器不通过容错或虚构提前退出替错误 ECA 放行。
- [ ] 非法类型组合明确失败；模型未实现的能力标明缺口，不用宿主语言真假值、默认对象或自动转换虚构引擎支持。模型失真时，历史测试结果已补充限制。
- [ ] 已验证相关数值、重复刷新、失去重获、无效记录、玩家隔离及涉及的时序；不适用项有说明。
- [ ] 多来源／多事件概率分别核对且不额外掷骰；拒绝奖励递归，已覆盖先赠结果再集齐组件及普通自然合成两条路径。
- [ ] 逐阶核对完整报价候选集合，而非只选择预定组件ID；不合格身份、终局及其他阵营不误开放，空／错后继配置不推进。
- [ ] 表与脚本同时修复时，以错误旧配置配合旧脚本重现缺陷，再验证新脚本仍能排除错误分类资源；未只用已纠正配表掩盖脚本缺口。
- [ ] 已覆盖左右普通终局、特殊终局的两种先后、另一线差一阶、锁定后当前组收尾及失败重试期间进度变化；离线／引擎各自未覆盖分支注明。
- [ ] 离线通过的范围和不能模拟的引擎行为分别记录。

## 写回与编辑器检查

- [ ] 共用函数在批量接入发布前已通过代表场景最小实战，记录输入、判定结果和最终行为；未执行则标明候选状态或负责人限定的离线交付范围。
- [ ] 有变更清单与备份；发布前核对当前版本，无并发改动被覆盖。
- [ ] 删除重复定义前已比较完整JSON及调用；同ID不同实现未直接删，精确移除副本和index项后，保留定义／ID、外部及递归引用不变，实际重开启动提示另行确认。
- [ ] 合并小改动已明确授权范围、每项检查与独立回退；共用函数仍按代表验证要求推进，未为局部变量过细拆分重启，也未把合批当作全资源实战通过。
- [ ] 定向修复核对测试候选哈希、目标原哈希及用户配置哈希，保留函数身份／签名和有效元数据；未重跑旧全量迁移器覆盖已发布工程或用户配表。
- [ ] 已写回并重载／保存回读，检查编辑器没有丢参数、把变量变常量或清空引用。
- [ ] 已按事件与参数写法检查页面红字、无效调用与错误资源引用；注明实际打开的资源范围。
- [ ] 写明全量扫描、页面抽查和未检查范围；没有把元数据或导出一致当成完整页面验收。
- [ ] 生成器／模板及测试模型与最终修复一致，历史候选和迁移器的适用范围明确。
- [ ] 临时自动发卡／强制概率探针与常驻调查日志分开登记；应撤节点及索引无残留，保留原生元数据未带回旧诊断，退役发布工具不可复跑。
- [ ] 候选、最小／全量写入、实际加载和实战进度分开；按类别统计唯一资源数、事件数、文件数，后加公共日志入口另行记账。

## 实战与报错归因

- [ ] 已记录获取、升级、合成、失去／重获、换波、补兵及战斗中实际执行的适用场景。
- [ ] 自动施法涉及的空闲、普攻中、其他主动技能施放中场景已检查，并确认允许场景实际执行施法；不适用项有说明。
- [ ] 已确认属性、奖励及技能等正向行为实际发生，撤销路径正确；没有仅凭警告减少、无报错或导出一致判定成功。
- [ ] 涉及关卡入口时已核对实际选关参数、查表结果、模式按钮和切图；负责人试玩反馈按明确范围登记，不把按钮恢复扩展为完整战斗验收。
- [ ] 检查重复应用、贡献撤销、来源销毁和多玩家隔离；填写未覆盖的边界。
- [ ] 延迟显示覆盖同帧连续变化、增减／清空／满格、不变状态、多单位、旧实例仍存在但已替换、回调前对象失效、换波重建和玩家／NPC方向；计时器清理与变量捕获分列离线／引擎证据。
- [ ] 已核对最新日志；错误按资源、节点及调用链定位，必要时与改动前日志比对。
- [ ] 当前日志空文件／尚未刷盘时未冒用旧样本；归档起止时间与会话范围，分别统计错误条数、不同节点数和业务类别，源文件未改与间接影响未证实分开表述。
- [ ] 自动测试 PASS／FAIL／SKIP 按实际日志登记；跳过样本未冒充通过，也未假定强制概率／补卡步骤已经执行。
- [ ] 获卡日志在写表后核验实际实例，记录玩家、卡牌 ID／名称、来源及结果；随机赠送含来源卡、事件、概率和原掷骰，EX 含实际结果及资格。
- [ ] 当前快照从有效持卡记录按类型去重，支持稀疏／重复／失效记录，排除英雄及其他拥有者；快照号与开始／结束配对，不能读到时引用最后有效记录。
- [ ] 唯一终局用获得流水及前后完整快照交叉核对：资格前无终局、来源正确、一次授予、后续另一线完成不再发放；未把返回已有实例当作新发卡证据。
- [ ] 进度／解锁修复使用新局验证；分类计数按实际范围解释，未因EX计数为0否定UR；未从缺少普通获卡记录推断全部UI选项均无该卡。
- [ ] 日志开关不影响玩法或随机数，周期未变化不刷屏；实际新局已检验输出，关键样本已归档；未执行的退出／断线／结算／多人分支单列待验证。
- [ ] 界面字段、实际持有和 UI 显示分别核对；长期概率结论有全部有效试次分母，未用仅含中奖的日志或单局体感推断掉率。
- [ ] 区分本模块直接错误、共享链旧问题和未经证明的间接影响，未越界修复暂缓模块。
- [ ] 多条件失败出口有必要的阶段／输入／中间值可定位原因，不只显示笼统合并提示；临时详细日志与敏感存档输出已检查清理。

## 性能优化适用项

- [ ] 已保留原采样与定位调用链，区分引擎自身、子事件和ECA重复工作；选择优化对象有实际耗时依据。
- [ ] 火焰图CPU毫秒、FPS、可见峰值、选中帧／悬浮帧及表格统计范围已区分；Total／Self与百分比分母核对，未跨调用层级相加总耗时。
- [ ] 前后地图版本、阵容／星级、卡牌、波次、兵力、运行模式／倍率、采样区间与选择范围可对照；普通帧和尖峰样本均保留，不同口径未换算提升比例。
- [ ] 行为等价、API读取／UI写入数、代表运行反馈和原生帧耗时分别验收；新增计时器、KV和条件成本未忽略，未用日志／警告减少替代性能实测。
- [ ] 追踪关闭后仍以实际施法、伤害及显示等正向行为判断功能，未用关闭日志的缺失认定技能未执行；性能尚未测得时明确写待验证。
