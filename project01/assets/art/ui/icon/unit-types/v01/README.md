# Unit Type Icons V01

Five 256x256 transparent PNG icons for unit categories, each supplied in selected and unselected states.

- infantry: dao saber
- archer: bow and arrow
- spearman: spear
- shield: round shield
- cavalry: horseshoe

`selected/` contains the selected-state production PNGs in the original antique-gold palette. `unselected/` contains nonselected PNGs rendered as complete grayscale icons, including the symbol, bronze frame, center texture, and four cardinal nodes. `transparent/` retains the original base renders. `source-chroma/` contains non-runtime color-key source files. `preview/` is only for visual QA.
