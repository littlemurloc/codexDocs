## 生成与实现边界

- 八套都保留开始挑战、武将阵容、兵种养成任务说明、在线补给和设置／退出。人物及章节数值为样例，不规定阵容上限。
- 成就、天赋按负责人决定撤下玩家入口，底层与存档保留。原公告聊天、选关占位、测试工具不在本轮重设计范围，未改变显隐和权限。
- 图片是基于已有素材生成的皮肤对照参考，AI 仍可能解释局部边角，不作为引擎截图或逐像素拼接证明。正式实装继续复用已列出的 ID，按实际九宫、字体、透明边缘与命中区域验证。
- 08 使用现有圆形开战印章，因此按钮轮廓与其他方案不同，功能没有增加，也没有强行把圆形素材拉成矩形。
- 最终图像尺寸、哈希与本轮新增范围见 [image-manifest.json](image-manifest.json)，公共及各套提示词见 [prompts.md](prompts.md)。08 首次主机响应超时且未找到输出文件，重试后成功，保留真实记录，不重复计作两张成果。

没有修改正式 UI、ECA、物编、配表或存档。旧方案与本轮所有候选均保留供负责人比较，没有因为未选中就自动删除。
