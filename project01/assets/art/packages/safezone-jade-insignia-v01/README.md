# 安全区青玉星标与武将品质徽章

Image2 生成的三国题材 UI 图标。独立 RGBA PNG 位于 `png/`，`source/` 提供源图与提示词。资源等比使用。

| 用途 | 规格 | 画面与对应档位 |
| --- | --- | --- |
| 武将星标 | 128 × 128，游戏内 20–22 像素 | 0 星空心铜，1–5 星金，6–10 星玉，11–15 星朱砂，16–20 星亮金 |
| 兵种星标 | 共用前三张 | 0 星空心铜，1–5 星金，6–10 星玉 |
| 武将品质 | 160 × 160，详情显示 54 像素 | N、R、SR、SSR、UR、SUR、TUR。品质按现有数值 1–7 对应 |

切片以源图 alpha 的实际外接框定位，去除 alpha 小于 12 的背景碎点，等比居中留边。检查图按游戏显示尺寸绘制。[浅底预览](preview_assets.png) · [深底与品红底检查](preview_alpha_check.png)

`manifest.json` 保存尺寸、源坐标和文件哈希。`y3-icons.json` 记录 Y3 导入后的资源 ID。星形图标沿用原有重复数量规则，武将列表的数值仍显示真实星数。
