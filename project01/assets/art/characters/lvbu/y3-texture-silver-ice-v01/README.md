## 在 Y3 中替换

1. 将新版身体 PNG 作为图片/图标资源导入 Y3，并记下新资源 ID。不要把角色立绘当作展开贴图。
2. 在截图中已有的“替换模型贴图”动作里，单位填“当前单位”，模型填“获取当前单位模型”，材质序号保留 `1`，贴图类型保留“颜色贴图”（当前保存值 `1`），最后的图片参数选择新版身体图。
3. 如需武器配套换色，再导入新版武器 PNG，增加一条同类动作，将材质序号设为 `2`，颜色贴图选新版武器图。该序号根据原材质实例中的顺序判断，需在游戏中确认。
4. 吕布当前把替换动作放在创建事件中。运行后新创建一名吕布检查效果，避免只观察在动作执行前已经存在的单位。
5. 从正面、背面、侧面检查脸、头发、披布、甲片接缝与戟刃。如出现错位，需要对原 UV 布局继续修正。
