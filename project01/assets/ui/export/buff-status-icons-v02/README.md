# Buff Status Icons v02

18 个单位状态图标，已统一为白银基底的透明 PNG。

## 规格

- 每张：`256x256` RGBA PNG
- 透明背景，四边 alpha 为 0
- 无文字、无卡牌底板；可直接用于公告板或特效贴图
