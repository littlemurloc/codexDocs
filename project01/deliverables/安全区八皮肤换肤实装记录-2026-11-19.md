## 检查范围

26 项离线检查直接执行候选 ECA 的表达式／动作树，不支持的接口会失败，不以宿主默认值容错。包括：八套保存 ID 恢复、64 组两两切换、取消及过期确认、重复点击去重、菜单 UI 事件从根登记后的分发、两玩家独立、缺模板、停用配置、写档失败回退、真实稀疏阵型与多于五位、进入原页面及返回。

静态检查包括：旧 UI 节点仅有登记的导航显隐差异、旧 ECA 仅多一处调用、旧存档槽不变、变量元数据完整、原索引保持、表／函数／UI 引用可解析、新身份无冲突、新 UI 事件名唯一、资源 ID 实际存在、九宫边距不超过目标控件大小、圆形印章等比。

离线模型把原页面 UI 事件记录为边界，未模拟 Y3 原生分页切换、原页面业务执行、真实纹理和字体渲染、网络上传或跨次存档。不能据此宣称原功能已完整回归。

Esc 常量按 [Y3 官方常量定义](https://github.com/y3-editor/y3-lualib/blob/main/doc/API/Const.md#y3constkeyboardkey) 的 `ESCAPE=1` 核对，事件结构沿用本图键盘抬起样本；与现有 Esc 行为的优先关系仍需运行测试。
