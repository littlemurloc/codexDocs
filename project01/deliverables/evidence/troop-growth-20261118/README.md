# 兵种养成迁移证据与源文件快照

对应[实装复盘](../../美食转兵种养成实装复盘-2026-11-18.md)。本目录是交付归档，仍需保留。

| 文件 | 用途 |
| --- | --- |
| `migration-manifest.json` | 五批原始／发布哈希、改名前后路径及最终 43 个发布路径、11 个移除路径 |
| `published-sources.zip` | 收尾时从实际工程读取的最终 43 个源文件，内部路径相对 `ProjectMonster02` |
| `before-by-phase.zip` | 五批共 54 份修改前局部源文件，内部先按批次分组，再按工程相对路径存放 |
| `function-renames.json` | 8 个函数的旧名、新名、FID 与地图内相对路径 |
| `archive-contract-check.json` | 发布时与收尾时的 26 个存档相关文件指纹，只有本地试玩档发生变化 |
| `final-check.json` | 最终候选内容、ID／索引、路径、品质池与存档静态核对结果 |
| `runtime-log-summary.json` | 四份日志的时段、Error／Warning 和重复事件统计，含改名前的 23:03 对照 |
| `runtime-warning-error-excerpts.txt` | 对应错误／警告行，未复制完整运行过程或玩家存档 |
| `cleanup-result.json` | 实际删除目录、文件数／体积和清理后保护检查结果 |

原始候选哈希与编辑器保存后的实际文件可能因格式不同而不同，`final-check.json` 登记 14 项解析内容一致的字节差异。发布包以实际工程文件为准。

两个 zip 均已逐成员校验哈希与压缩包完整性，不包含账户存档或一次性发布脚本。它们仅覆盖本次修改文件，不是整图备份，也不是可独立启动的地图。

回退时先确认批次、涉及后续修改及引用关系，在当前工程上比较差异。需要恢复改名前文件时，同时处理对应新路径与索引，不能将旧源与新索引混用。不提供自动覆盖命令，防止误把后来修改恢复成旧版本。

当前仍有重复事件警告和未实现的空池扣费保护，详见复盘。`PASS` 只表示登记的静态检查通过，负责人试玩反馈和未验证边界另行记录。
