# 军略技能作用描述表填写指南 v1

> 状态：当前军略技能描述配置与校验指南。本文服务于主策划、配置人员和程序顾问；军略效果与玩家可见简易描述以《三国斗阵-军令效果设计清单-V1》为准。

## 使用范围

本指南规定如何根据 `config_军令卡牌技能表.xlsx`，向 `config_技能作用描述表.xlsx` 填写或更新军略技能描述。它只处理玩家可见的类型标记与描述，不决定军略实际效果、数值、价格、抽取权重、解锁条件或技能 ID。

适用对象：

- 军令 Set 的 3 张组件卡。
- Set 完成后自动获得的合成/升级结果卡。
- 已配置进入 `config_军令卡牌技能表.xlsx` 的新增军略技能。
- 已确认军略效果变更后的描述同步。

不适用对象：

- 英雄技能描述配置，适用 [技能作用描述表填写指南 v1](skill-description-table-authoring-guide-v1.md)。
- 尚未配置 ID 的独立军略、道具、怪物原生技能。
- 军略效果或数值的首次设计与平衡调整。

## 使用前必读

按以下优先级确认信息：

1. 项目负责人最新明确口径。
2. 当前 `config_军令卡牌技能表.xlsx`：决定本轮应覆盖的有效 `ability_type`、所属 Set 与是否合成。
3. `deliverables/三国斗阵-军令效果设计清单-V1.docx`：决定军略是主动或被动，以及写入配置表的“游戏内简短描述”。不得以实现说明、预警时长或内部流程替代该简易描述。
4. 本指南：决定描述表的字段填法与交付校验。

若卡牌表 ID、所属 Set、合成标记与设计清单无法一一对应，不得凭记忆补写；先记录冲突并请主策确认。

## 两张表的职责

| 文件 | 负责内容 | 不应承担的内容 |
| --- | --- | --- |
| `config_军令卡牌技能表.xlsx` | 军略 `ability_type`、所属 Set、是否合成与市场相关配置。 | 玩家可见描述、主动/被动文案判断、擅自改写军略效果。 |
| `config_技能作用描述表.xlsx` | 每个有效 `ability_type` 的类型倾向标记、默认描述与等级描述。 | 反推军略 ID、修改卡牌价格/Set/解锁逻辑，或改动实际效果。 |

填表时必须先从军令卡牌表读取 ID；不得从截图、历史行号或卡牌名称猜测 ID。

## 当前卡牌表读取规则

当前 `config_军令卡牌技能表.xlsx` 的每一行均代表一个需要显示描述的军略技能：

| 字段 | 含义 | 描述表处理 |
| --- | --- | --- |
| `技能类型` | 军略的 `ability_type`。 | 每个有效 ID 在描述表中只保留 1 行。 |
| `所属set` | 军略所属 Set。 | 用于与设计清单的对应 Set 交叉核对。 |
| `是否合成` | 是否为 Set 完成后自动获得的合成/升级结果。 | 无论 `true` 或 `false` 均必须填写描述。 |

当前基线为 9 个 Set、每 Set 3 张组件卡加 1 张结果卡，共 36 条军略 ID，其中 27 条组件卡、9 条合成/升级结果卡。

当前卡牌表未提供卡牌名称字段。映射时须先按 `所属set` 分组，再按该 Set 在《三国斗阵-军令效果设计清单-V1》中的组件顺序与结果卡顺序核对；`是否合成 = true` 的记录对应该 Set 的自动结果。不得仅依赖整表行号跨 Set 推断。

## 描述表字段

| 字段 | 填写规则 |
| --- | --- |
| `key` | 描述表内唯一键。既有记录不重排；新增记录从当前最大值继续递增。 |
| `技能类型` | 直接填写军令卡牌表读取到的有效 `ability_type`，以文本 ID 保持原表格式。 |
| `类型倾向标记` | 只能填 `主动` 或 `被动`，以军令效果设计清单的卡牌类型为准。 |
| `默认描述` | 军略技能的玩家可见简易描述。 |
| `技能描述等级1` 至 `技能描述等级10` | 按技能等级读取的描述字段。 |

当前军略不存在按 `skill_rank` 变化的独立描述档位；组件与合成/升级结果使用不同 ID，而非同一 ID 的等级变化。因此当前填法为：

- `默认描述` 与 `技能描述等级1` 至 `技能描述等级10` 填写同一份已确认的简易描述。
- 合成/升级后的结果卡必须另占 1 行，不得覆盖其组件卡的 ID 或描述。
- 未来若同一军略 ID 开放真实等级成长，必须先确认每一级实际效果，再逐级改写对应描述。

## 简易描述写法

军略描述必须优先采用《三国斗阵-军令效果设计清单-V1》的“游戏内简短描述建议”。该字段是面向玩家的文案，不是完整实现说明。

描述应保留影响玩家判断的目标、数量、阈值、持续时间、层数、资源收益与位置条件，例如“指定一路”“每波首次”“前排”“侧翼”“队长/精英”。

描述不应：

- 补入未写入简易描述的预警时间、返还条件、内部锁定步骤或技术字段。
- 使用“多次”“短时间”“附近”等缺少数量边界的模糊词，除非设计主源本身没有更明确口径。
- 把合成卡误写为组件卡效果，或把主动/被动类型按 `是否合成` 直接推断。
- 因配置方便改变军略的战前路归属、前中后排、侧翼、队长/小兵或资源条件。

## 填表流程

1. 打开军令卡牌表，读取所有有效 `技能类型`，检查 ID 非空且不重复。
2. 按 `所属set` 与 `是否合成` 将每条 ID 映射到军令效果设计清单中的组件或自动结果卡，并确认其主动/被动类型。
3. 从《三国斗阵-军令效果设计清单-V1》的“游戏内简短描述建议”摘取文案；不得以完整效果说明替代。
4. 在技能作用描述表按 `技能类型` 查找：已有 ID 时只更新类型标记和描述；没有 ID 时才在末尾新增 `key`。
5. 写入 `默认描述` 与等级 1 至 10 描述字段；当前版本全部填入同一份简易描述。
6. 保留卡牌表的 ID、Set、合成、解锁、价格与其他无关字段；不得因补描述改动军令卡牌表。
7. 导出后回读首条、任一中间 Set 和末条结果卡，并执行覆盖与文本完整性校验。

## 提交前校验

### 结构校验

- 军令卡牌表的每个有效 `技能类型` 都在描述表中恰有 1 条记录。
- 当前 36 条军略记录均已覆盖：27 条组件卡与 9 条合成/升级结果卡均不可遗漏。
- 描述表中无重复军略 ID，`key` 唯一，既有记录未重排。
- 所有 ID 保持文本格式，不转换成科学计数法或截断数值。
- 未配置进军令卡牌表的独立军略不得擅自新增到描述表。

### 文案校验

- `类型倾向标记` 与军令效果设计清单一致。
- 默认描述与等级 1 至 10 描述不为空，且使用该文档的简易描述口径。
- 目标路、前中后排/侧翼、队长/精英、数量、百分比、持续时间、层数与资源条件未被遗漏或改写。
- 合成/升级结果卡的描述与组件卡存在明确区分。

### 技术与交付校验

- 不修改 `config_军令卡牌技能表.xlsx` 的 ID、Set、合成与市场相关字段。
- 检查无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或 `#N/A`。
- 渲染确认描述列已换行、行高足以显示长文本，首条与末条均无裁切。
- 交付目录只保留实际 `.xlsx` 配置文件；删除检查工具生成的临时输出。

## 当前基线记录

截至本指南创建时，`config_军令卡牌技能表.xlsx` 中已配置 36 条军略 ID，均已写入 `config_技能作用描述表.xlsx`。描述表当前由 108 条英雄技能与 36 条军略技能构成，共 144 条有效记录。该数量仅用于本轮回归核对，不应作为未来扩充的固定上限。
