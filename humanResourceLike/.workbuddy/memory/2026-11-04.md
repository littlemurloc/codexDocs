## 手机版「一直是横屏」——方向被 project.godot 钉死了

达叔跑 APK 反馈：切竖版/横版只是换 UI 布局，画面一直横着。

根因不在代码，在 `project.godot`：`display/window/handheld/orientation=4`
（SCREEN_SENSOR_LANDSCAPE）→ APK manifest 里 `screenOrientation=userLandscape(11)`，
系统强制横屏，竖着拿就把画面转 90°。

改成 `6`（SCREEN_SENSOR）→ manifest 变成 `fullUser(13)`，四个方向都行且尊重系统方向锁。

代码侧补三端分路：
- 手机：`DisplayServer.screen_set_orientation()`，布局永远跟随窗口（不强制）
- 浏览器：全屏 + orientation.lock（老样子）
- 桌面：直接切布局（预览）

重导 APK（manifest 已验 = 13），Web 也重导。回归 124/5/244 全绿。
