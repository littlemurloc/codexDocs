# 2026-11-09

## 竖屏指令条：横滑与点选冲突（达叔反馈）

**问题**：手机竖版里底部指令牌，左右滑动会同时触发点选 → 滑一下条子就白放一张牌。

**改动**（`hrm_godot/scripts/main.gd`）：
- 新增 `_pal_gesture()`：一个手势三出口，按**方向**判 —— `|dx|>=|dy|` 滚条子、纵向拿起牌、
  位移 < `PAL_SWIPE_PX`(14) 松手算点选。判成滑动立刻 `_press_on = false` 作废这次按下
  （否则松手被 release 分支当成点击）。
- 新增 `_pal_mouse_scroll()`：鼠标没有 ScreenDrag，另开一条 MouseMotion 通道做横滑
  （`|dx| > |dy|*1.5` 才算横滑），否则桌面/调试窗左右拖牌条 = 幽灵卡跟着走。达叔正是这样
  发现「滑动区域写错了」。
- 新增 `_on_palette_tap()` / `_set_pal_sel()` / `_paint_palette_card()`：**竖屏两步确认**
  （第一下只选中：换底色 + 白描边 + 字反深色；第二下同一张才追加；纵向拖出去=确认；
  手落到别处=收回选中）。横屏单击仍直接追加。三态（选中/引导/普通）只走一个绘制出口。
- `_end_drag()` 成功分支也 `_update_insert_hint()`：原来放下后屏幕一直挂「松手 → 插到第 N 行」。
- 新文案「已选 %s · 再点一次放到第 %d 行」补进 `data/i18n.json` 的 `en` 表，并
  `gen_hant.py --write` 重烘繁体。

**验证**：`test_levels` 124 / `test_ideas` 5 / `test_ui` 258（横屏）+ 258（390×844）全绿；
`scan_strings.py --check` 171/171、116/116；新探针 `tools/probe_palette.gd`（412×844）13 项全过
（触摸横滑不选不追加、点选两步、纵向拖入、鼠标横拖不拖牌）。截图 `_shots/pal_sel_412.png`。

**坑**：`--script` 模式下 `get_viewport().get_texture().get_image()` 拿到的是「最后一次 present
的帧」，流程中途截图等于截到末尾 —— 带 `--shot` 时探针跑到选中态就 quit。

## 追加：牌条「左右滑不动」（达叔第二次反馈）

上一版加了鼠标横滑通道，但**起拖阈值还是固定 5px**：真人拖动每帧 2~4px，到 6px 就已经
`_start_drag()` 变成幽灵卡跟着走，`_pal_mouse_scroll` 要的 14px 永远等不到 → 牌条彻底滑不动。

修法：新增 `_drag_threshold()`，竖屏牌条上「横向为主」时起拖阈值抬到 `PAL_SWIPE_PX`(14)，
「纵向为主」仍 5px（往上提立刻拿起牌）。触摸的纵向拿牌也从 14px 降到 5px（DRAG_START_PX），
和列表拖行同门槛。

探针 `probe_palette.gd` 的鼠标用例改成两档步长（2px/帧、20px/帧）。**并先证明它抓得住 bug**：
把阈值临时改回固定 5，用例报「鼠标横拖（每帧 2px）应滚条子（80 → 80）」FAIL；还原后 16/16 全过。
教训：大步长探针会掩盖手感类 bug。

## 手机报「底部卡片拖拽后图片残留」

复现与修复（`main.gd`）：
1. `_index_at()` 先排除牌条矩形（`grow(8)` 命中就返回 -1）。原来 `panel_prog.grow(40)` 盖到牌条上沿，
   在牌条里松手会被算成「插到最后一行」→ 程序凭空多一行。探针复现到了这条（31 → 32）。
2. `_start_drag()` 建幽灵卡前先 `_clear_drag_nodes()`：`_ghost` 只有一个引用，重复建就把上一张
   丢在屏幕上没人释放。
3. 松手收尾加两道兜底：`_pal_gesture` 里 `_drag_on` 但 `_pal_drag` 为假时也 `_end_drag(false)`；
   `_input` 里「任何 index==0 的触摸抬起 + `_drag_on`」一律收尾（不再依赖牌条矩形与模拟鼠标事件）。
4. `_begin_press()` 在 `_drag_on` 时直接 return；`_pal_gesture` 只认 `index == 0`。
   （多指用例在桌面 push_input 下不可靠 —— 引擎会把它模拟成鼠标事件走另一条路，已从探针删掉，
   代码防御保留。）
5. 横滑判定成立时若已在拖牌态，`_end_drag(false)` 把幽灵卡当场收掉。

探针 `probe_palette.gd` 新增两条用例（牌条内轻拖后松手、先上抖再横划后松手），25 项全过；
`test_ui` 258（横屏）+ 258（竖屏）、`probe_swipe` 全绿。新 APK 17:56 导出（旧包先删）。
