CRISP KIT - Free Sampler
========================

A flat, rounded UI kit for casual and mobile-style games: 100 themed pieces in 8 colour themes,
127 icons, 93 input prompt glyphs and 15 colour pieces (stars, coin, gem, heart...).

GET THE FULL PACK
  This free sampler has 57 pieces: 26 from the mint theme, 3 colour pieces,
  20 icons and 8 input prompts.
  The full pack has 1255 images (3765 files), all 8 themes and the Godot 4 themes.
  GET THE FULL PACK: https://anipixels.itch.io/crisp-kit

WHAT IS IN THE ZIP
  PNG/1x/         every piece at base size (made for roughly 960 x 540 to 1280 x 720 layouts)
  PNG/2x/         the same pieces at double size (1080p and up, phones, HiDPI)
  SVG/            the same pieces as vector files
  sheets.json     every piece: file paths, sizes, 9-slice borders, content padding, notes

FOLDERS INSIDE PNG AND SVG
  mint, common, icons_white, prompts_light
  (the full pack has 8 themes, both icon colours and both prompt styles)

9-SLICE PIECES
  65 of the 100 themed pieces are 9-slice (or 3-slice) frames: buttons, panels, windows, bars, tabs, inputs, bubbles.
  Their borders are in sheets.json (slice_1x / slice_2x, in pixels from each edge). Stretch the middle, keep the corners.
  A note of 'fixed height' means the piece only stretches sideways. progress_fill_striped tiles its centre.
  Button states share one canvas size; the pressed face sits lower, with a thinner lip.

INPUT PROMPTS
  Keyboard: A-Z, 0-9, arrows, Esc, Tab, Ctrl, Alt, Shift, Enter, Space, Backspace and two blank keys.
  Mouse: plain, left, right, middle, scroll, scroll up, scroll down.
  Gamepad: generic glyphs only - A/B/X/Y letters, plain face-button diamonds, d-pad directions, LB/RB/LT/RT,
  sticks (L/R, click, four directions), Start/Select/Menu/View. No console logos or trademarked symbols.

FONTS
  No font is included. The lettering on the key and gamepad prompts is drawn as shapes by the same code.
  The screenshots and web demo use the system font (Segoe UI Black on Windows). Any rounded bold font suits
  the kit, for example the free Baloo 2, Fredoka or Nunito (SIL Open Font License, from Google Fonts).
